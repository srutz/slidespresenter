
# 22.21 SemVer und npm (Zusatzthema) / Weitere nützliche Befehle

## Ergänzende Kommandos rund um Versionen und Abhängigkeiten

```bash
npm explain react        # wie npm ls, aber mit vollständiger Begründung (Alias: npm why)
npm pack                 # erzeugt das .tgz, das npm publish hochladen würde - guter Vorab-Check
npm prune                # entfernt Pakete aus node_modules, die nicht mehr in package.json stehen
npm dedupe --dry-run     # zeigt, was dedupe ändern würde, ohne es zu tun
npm config get           # zeigt aktive npm-Konfiguration (z. B. registry, save-exact)
npm doctor               # prüft die npm-Umgebung selbst (Registry erreichbar, Cache ok, Node-Version, ...)
```

- `npm outdated`, `npm update`, `npm audit`, `npm ls` und `npm why` sind die Befehle, die man im Alltag am häufigsten braucht - die hier ergänzen sie für Spezialfälle (Debugging, CI, Release-Vorbereitung).

# 8.2 useHooks als Standard-Hook-Sammlung / Standard-Hooks auswählen und einsetzen

## Wichtige Hooks im Überblick

| Hook | Aufruf | Ergebnis |
|---|---|---|
| `useDebounce` | `useDebounce(value, delay)` | verzögerter Wert |
| `useLocalStorage` | `useLocalStorage(key, initialValue)` | `[value, setValue]` |
| `useMediaQuery` | `useMediaQuery(query)` | `boolean` |
| `useClickAway` | `useClickAway(callback)` | `ref` für das Element |
| `useWindowSize` | `useWindowSize()` | `{ width, height }` |
| `useToggle` | `useToggle(initial?)` | `[on, toggle]` |
| `useCopyToClipboard` | `useCopyToClipboard()` | `[copiedText, copy]` |
| `usePrevious` | `usePrevious(value)` | Wert des vorigen Renders |
| `useIntersectionObserver` | `useIntersectionObserver(options)` | `[ref, entry]` |

- Signaturen immer in der Dokumentation bzw. im Quellcode gegenprüfen, die Doku auf usehooks.com ist knapp

# 8.2 useHooks als Standard-Hook-Sammlung / Kleine Beispiele

```typescript
import { useToggle, usePrevious, useCopyToClipboard } from '@uidotdev/usehooks'

export function Demo() {
    const [open, toggleOpen] = useToggle(false)
    const [count, setCount] = useState(0)
    const previous = usePrevious(count)
    const [copied, copyToClipboard] = useCopyToClipboard()

    return (
        <div>
            <button onClick={() => toggleOpen()}>{open ? 'Schließen' : 'Öffnen'}</button>
            <button onClick={() => setCount(count + 1)}>Jetzt: {count}, vorher: {previous}</button>
            <button onClick={() => copyToClipboard('npm i @uidotdev/usehooks')}>Kopieren</button>
            {copied && <p>Kopiert: {copied}</p>}
        </div>
    )
}
```

# 8.2 useHooks als Standard-Hook-Sammlung / Auswahlkriterien

- Löst der Hook genau **ein** klar umrissenes Problem, das wir nicht selbst pflegen wollen?
- Ist das Verhalten im Browser komplex genug (Event-Listener, Cleanup, SSR, Browser-Unterschiede)?
- Gibt es in React 19 oder im Browser bereits eine einfachere Lösung (z. B. `useDeferredValue`, CSS `:hover`, Container Queries statt `useMediaQuery`)?
- Server-Daten gehören nicht in `useFetch`, sondern in TanStack Query
- Globaler State gehört nicht in `useLocalStorage`, sondern in Zustand (mit `persist`)

# 11.13 Formulare und Validierung / Komplexere und wiederverwendbare Formular-Komponenten

## Wiederverwendbare FormField-Komponente

- Label, Input und Fehlermeldung wiederholen sich in jedem Formular, daher lohnt sich eine eigene Komponente.
- Mit `forwardRef` entfällt in React 19: `ref` ist ein normaler Prop.
- `register(...)` liefert `name`, `onChange`, `onBlur` und `ref` und wird einfach als Props verteilt.

```typescript
import type { ComponentProps } from 'react'
import type { FieldError } from 'react-hook-form'

type FormFieldProps = ComponentProps<'input'> & {
    label: string
    error?: FieldError
}

export function FormField({ label, error, id, ...inputProps }: FormFieldProps) {
    const inputId = id ?? inputProps.name
    return (
        <div className="flex flex-col gap-1">
            <label htmlFor={inputId}>{label}</label>
            <input id={inputId} aria-invalid={!!error} {...inputProps} />
            {error && <p role="alert" className="text-sm text-red-600">{error.message}</p>}
        </div>
    )
}

// Verwendung
<FormField label="E-Mail" error={errors.email} {...register('email')} />
```

# 11.13 Formulare und Validierung / FormProvider und useFormContext

## Formular-Kontext statt Prop Drilling

- `FormProvider` stellt das `useForm`-Objekt per Context bereit.
- Tief verschachtelte Felder holen sich `register` und `formState` mit `useFormContext`.
- Ein Feld-Typ, der den Namen aus dem Schema typsicher übernimmt, vermeidet Tippfehler.

```typescript
import { FormProvider, useForm, useFormContext, type FieldValues, type Path } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'

function TextField<T extends FieldValues>({ name, label }: { name: Path<T>; label: string }) {
    const { register, formState: { errors } } = useFormContext<T>()
    const error = errors[name]
    return (
        <div>
            <label>{label}<input {...register(name)} /></label>
            {error && <p role="alert">{String(error.message)}</p>}
        </div>
    )
}

export function ProfileForm() {
    const methods = useForm<Profile>({ resolver: zodResolver(profileSchema) })
    return (
        <FormProvider {...methods}>
            <form onSubmit={methods.handleSubmit(save)}>
                <TextField<Profile> name="name" label="Name" />
                <button type="submit">Speichern</button>
            </form>
        </FormProvider>
    )
}
```

# 11.13 Formulare und Validierung / Controller für nicht native Eingaben

## Controller und useController

- Komponenten ohne `ref` auf ein natives Input (Selects aus UI-Libraries, Datepicker, Slider) sind **kontrollierte** Komponenten.
- `Controller` verbindet sie mit RHF über `value`, `onChange`, `onBlur`.

```typescript
import { Controller, useForm } from 'react-hook-form'

type Settings = { volume: number }

export function VolumeForm() {
    const { control, handleSubmit } = useForm<Settings>({ defaultValues: { volume: 50 } })

    return (
        <form onSubmit={handleSubmit(console.log)}>
            <Controller
                name="volume"
                control={control}
                render={({ field, fieldState }) => (
                    <>
                        <input type="range" min={0} max={100}
                            value={field.value}
                            onChange={(e) => field.onChange(e.target.valueAsNumber)}
                            onBlur={field.onBlur} />
                        {fieldState.error && <p role="alert">{fieldState.error.message}</p>}
                    </>
                )}
            />
        </form>
    )
}
```

# 11.13 Formulare und Validierung / Dynamische Felder mit useFieldArray

## Listen von Eingaben

- `useFieldArray` verwaltet Arrays im Formular: `fields`, `append`, `remove`, `move`.
- Als `key` immer `field.id` verwenden, nicht den Index.
- Das Zod-Schema beschreibt das Array, der Typ wird daraus abgeleitet.

```typescript
const schema = z.object({
    title: z.string().min(1, 'Titel fehlt'),
    items: z.array(z.object({ name: z.string().min(1, 'Name fehlt'), qty: z.number().int().min(1) }))
        .min(1, 'Mind. eine Position'),
})
type OrderData = z.infer<typeof schema>

const { register, control, handleSubmit } = useForm<OrderData>({
    resolver: zodResolver(schema),
    defaultValues: { title: '', items: [{ name: '', qty: 1 }] },
})
const { fields, append, remove } = useFieldArray({ control, name: 'items' })

// JSX
{fields.map((field, index) => (
    <div key={field.id}>
        <input {...register(`items.${index}.name`)} />
        <input type="number" {...register(`items.${index}.qty`, { valueAsNumber: true })} />
        <button type="button" onClick={() => remove(index)}>Entfernen</button>
    </div>
))}
<button type="button" onClick={() => append({ name: '', qty: 1 })}>Position hinzufügen</button>
```

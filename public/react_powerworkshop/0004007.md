# 4.7 Styling mit Tailwind CSS / Layout mit Flexbox und CSS Grid

## Flexbox

- `flex` aktiviert Flexbox, `flex-col` ändert die Richtung auf vertikal
- Hauptachse: `justify-start`, `justify-center`, `justify-between`, `justify-end`
- Querachse: `items-start`, `items-center`, `items-stretch`
- Abstände: `gap-4`, `gap-x-2`, `gap-y-6`
- Umbruch: `flex-wrap`
- Kinder: `flex-1` (Platz füllen), `shrink-0` (nicht schrumpfen), `ml-auto` (nach rechts schieben)

```typescript
<header className="flex items-center justify-between gap-4 border-b px-6 py-3">
  <h1 className="text-lg font-semibold">Shop</h1>
  <nav className="flex gap-4 text-sm">
    <a href="/products">Produkte</a>
    <a href="/cart">Warenkorb</a>
  </nav>
</header>
```

## CSS Grid

- `grid` aktiviert Grid, `grid-cols-3` erzeugt drei gleich breite Spalten
- Zeilen: `grid-rows-2`, automatische Zeilenhöhe ist Standard
- Zellen über mehrere Spalten: `col-span-2`, `col-span-full`, `row-span-2`
- Flexible Spalten: `grid-cols-[200px_1fr]` (feste Sidebar, flexibler Inhalt)
- Automatisch füllen: `grid-cols-[repeat(auto-fill,minmax(16rem,1fr))]`
- `gap-4` gilt wie bei Flexbox
- Faustregel: Flexbox für eindimensionale Anordnung (Zeile oder Spalte), Grid für zweidimensionale Layouts

## Typisches Page-Layout

```typescript
export function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <div className="grid min-h-screen grid-rows-[auto_1fr_auto]">
      <header className="bg-slate-900 px-6 py-4 text-white">Header</header>
      <div className="grid md:grid-cols-[16rem_1fr]">
        <aside className="hidden border-r bg-slate-50 p-4 md:block">Navigation</aside>
        <main className="mx-auto w-full max-w-4xl p-6">{children}</main>
      </div>
      <footer className="border-t px-6 py-4 text-sm text-slate-500">Footer</footer>
    </div>
  )
}
```

- Footer bleibt unten, Sidebar erscheint erst ab Tablet-Breite, der Inhalt wird auf `max-w-4xl` begrenzt und zentriert


# 10.11 Routing mit React Router / Bearbeitung des 404-Errors

## Catch-All-Route

- Wenn der Benutzer eine unbekannte Route aufruft ist es ratsam eine eigene Catch-All Route anzuzeigen. Diese wird am Ende des Router-Objekts definiert.

```typescript
const router = createBrowserRouter([
    {
        path: "/",
        element: <Main />,
    },
    { 
        path: "*", 
        element: <Error>We haven't found where you were looking for</Error> 
},
])
```

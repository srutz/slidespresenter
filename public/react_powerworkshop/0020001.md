# React 19 Topics

## React Compiler

- Der React-Compiler memo'ized vollständig.
- Die Benutzung von `useMemo`, `useCallback` und `React.memo` ist nicht mehr notwendig.
- Dead-Code Eliminierung wird ebenfalls vom Compiler durchgeführt.

- Der Compiler kann auf [https://playground.react.dev/](https://playground.react.dev/) getestet werden.

- Beispiel für den Compiler:

[https://github.com/srutz/reactempty19](https://github.com/srutz/reactempty19)


# React 19 Topics 

## React Compiler 2

In der Config des Compilers kann spezifisch eingestellt werden, wie der Compiler arbeiten soll.

Beispiel für die vite.config.ts:

```typescript
declare const console: any;
export default defineConfig({
    plugins: [
        react({
            babel: {
                plugins: [
                    ["babel-plugin-react-compiler", {
                        sources: (filename: any) => {
                            console.log("filename")
                            return true
                        }
                    }],
                ],
            },
        }),
        tailwindcss(),
    ],
})
```

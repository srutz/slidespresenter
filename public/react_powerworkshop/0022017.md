
# 22.17 SemVer und npm (Zusatzthema) / npm view und npm why

## npm view (bzw. npm info) - Paket-Metadaten abfragen

```bash
npm view react                 # alle Metadaten zur "latest"-Version
npm view react versions        # Liste aller je veröffentlichten Versionen
npm view react version         # nur die aktuell "latest" markierte Version
npm view react@18 versions     # alle 18.x Versionen
```

- Fragt direkt die Registry ab, ohne etwas zu installieren - nützlich, um vor einem Update zu prüfen, welche Versionen überhaupt existieren.

# 22.17 SemVer und npm (Zusatzthema) / npm why

## npm why - Warum ist ein Paket installiert?

```bash
npm why react
```

```
react@18.3.1
node_modules/react
  peer react@"^18.0.0" from some-ui-lib@2.0.0
  node_modules/some-ui-lib
    dependencies from the root project
```

- Zeigt die komplette Kette von Abhängigkeiten, die zur Installation eines bestimmten Pakets geführt haben.
- Sehr hilfreich, um unerwartete oder doppelte Versionen (siehe `npm ls`) zurückzuverfolgen und zu verstehen, welches Paket eine bestimmte Version "verlangt".

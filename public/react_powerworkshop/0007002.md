# 7.2 Hooks und moderne React Patterns / Verwenden von "useState()" für Zustandsverwaltung

## useState() Infos

- useState() ist ein Hook, der in Funktions-Komponenten verwendet wird, um Zustände zu verwalten
- useState() gibt ein Array zurück, das den aktuellen Zustand und eine Funktion zum Aktualisieren des Zustands enthält

- Bei einem Re-Render wird der aktuelle Zustand in der Komponente behalten (quasi in einer internen Variable die am HTML-Element hängt)

- Bei einem Re-Render wird der aktuelle Zustand in der Variable zurückgegeben.

- Eine Änderung des Zustands wird durch die Funktion zum Aktualisieren des Zustands ausgelöst und führt zu einem Re-Render der Komponente.

- Das bedeutet, dass Änderungen einer Objekteigenschaft nicht erkannt werden. Ebenso werden Änderungen von Array-Elementen nicht erkannt.

## Kopieren von Arrays und Objekten mittels Spread-Operator

- Der Spread-Operator `...` kann verwendet werden, um Arrays und Objekte zu kopieren.

- Arrays können mittels `...` kopiert werden:

```typescript
const arr = [1, 2, 3]
const newArr = [...arr]
```

- Objekte können mittels `...` kopiert werden:

```typescript
const obj = { a: 1, b: 2, c: 3 }
const newObj = { ...obj }
```

## useState() und das Kopieren von Arrays und Objekten mittels Spread-Operator

- Wenn ein Array oder ein Objekt in einem Zustand gespeichert wird, sollte es kopiert werden, bevor es geändert wird.

```typescript
const [arr, setArr] = useState([1, 2, 3])

// Falsch: Direkte Änderung des Arrays
arr.push(4)

// Richtig: Kopieren des Arrays und Hinzufügen eines Elements
const newArr = [...arr, 4]
```

- Ebenso kann dieses Idiom bei Objekten angewendet werden:

```typescript
const [obj, setObj] = useState({ a: 1, b: 2, c: 3 })

// Falsch: Direkte Änderung des Objekts
obj.d = 4

// Richtig: Kopieren des Objekts und Hinzufügen eines Elements

const newObj = { ...obj, d: 4 }
```

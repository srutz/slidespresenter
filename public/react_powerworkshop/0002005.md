
# 2.5 React Einführung / Projekt erstellen mit "Vite"

## Vite

- Vite ist der Standard-Bundler/Dev-Server für neue React-Projekte (JavaScript und TypeScript)
- Vite hat "create-react-app" abgelöst (CRA ist deprecated) und ist schneller und einfacher zu konfigurieren
- Im Seminar starten wir TypeScript von Beginn an: Template "React" + "TypeScript"
- Vite ist ein "ESM first" Bundler, d.h. er unterstützt native ES Modules.

# 2.5 React Einführung / Projekt erstellen mit "Vite"

## React-Projekt mit Vite erstellen

- Um ein React-Projekt mit Vite zu erstellen, führen Sie folgende Schritte aus:

```bash
npm create vite@latest
```

- Wählen Sie "React" als Framework und "TypeScript" als Variante aus (Template `react-ts`)
- Wählen Sie einen Projektnamen aus
- Wechseln Sie in das Projektverzeichnis
- Installieren Sie die Abhängigkeiten

```bash
cd mein-react-projekt
npm install
```

- Starten Sie den Dev Server

```bash
npm run dev
```

## Vites Proxy

- Vite hat einen eingebauten Proxy, der es ermöglicht, Anfragen an einen anderen Server weiterzuleiten
- Dies ist besonders nützlich, wenn Sie eine API verwenden, die auf einem anderen Server läuft und Sie durch CORS Konfigurationen eingeschränkt sind
- Um den Proxy zu konfigurieren, fügen Sie die beispielsweise folgendes zu Ihrer `vite.config.js` hinzu:

```javascript
export default {
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  }
}
```

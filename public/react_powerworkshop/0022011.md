
# 22.11 SemVer und npm (Zusatzthema) / package-lock.json

## Warum eine Lock-Datei?

- `package.json` beschreibt nur **erlaubte Bereiche** (`^1.2.3`) - nicht, welche exakte Version tatsächlich installiert wurde.
- Ohne weitere Vorkehrungen könnten zwei Entwickler, die zu unterschiedlichen Zeitpunkten `npm install` ausführen, leicht unterschiedliche Versionen (und damit unterschiedliches Verhalten) erhalten.
- `package-lock.json` löst dieses Problem: Sie hält für **jede** installierte Abhängigkeit (auch transitive!) die exakte Version, Herkunfts-URL und einen Integritäts-Hash fest.

## Konsequenz

- Solange `package-lock.json` vorhanden ist und respektiert wird, führt `npm install` bei jedem Entwickler und auf jedem CI-Server zur **exakt gleichen** `node_modules`-Struktur.
- `package-lock.json` sollte immer in die Versionskontrolle (git) eingecheckt werden - im Gegensatz zu `node_modules`.

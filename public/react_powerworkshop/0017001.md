# 17.1 Legacy- und Überblicksthemen / Bewusst nur noch Legacy- und Überblicksthemen

## Was Sie kennen sollten, aber nicht mehr neu einsetzen

| Legacy-Thema | Warum Legacy | Moderne Alternative | Kapitel |
|---|---|---|---|
| Create React App | Seit 2025 deprecated, nicht mehr gepflegt | Vite | 2, 17.2 |
| Klassenkomponenten und Lifecycle | Mehr Boilerplate, schwer wiederverwendbare Logik | Funktionskomponenten und Hooks | 7 |
| Higher-Order Components | Verschachtelte Wrapper, unklare Props-Herkunft | Custom Hooks, Composition | 7, 15.3 |
| `contextType` | Nur in Klassen, nur ein Context | `useContext` | 17.2 |
| Klassisches Redux | Viel Boilerplate, Server State im Store | Zustand, TanStack Query | 9, 12 |
| Emotion / Styled Components | Laufzeit-CSS, Probleme mit Server Components | Tailwind CSS, CSS Modules | 4 |

- Legacy-Wissen ist wichtig, weil bestehende Codebasen diese Muster oft enthalten.
- Die folgenden Folien zeigen sie kompakt, damit Sie sie lesen und schrittweise migrieren können.

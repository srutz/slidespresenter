
# 10.4 Routing mit React Router / Navigation mit Links

## Link Component

- Um auf der gleichen Seite zu bleiben, aber dennoch die URL zu ändern, muss man die Komponente `Link` aus `react-router` anstatt eines `a`-Tags verwenden.

```typescript
import { Link } from 'react-router';

export function Navigation() {
    return (
        <div>
            <h1>Navigation</h1>
            <ul>
                <li><Link to="/">Home</Link></li>
                <li><Link to="/about">About</Link></li>
                <li><Link to="/contact">Contact</Link></li>
            </ul>
        </div>
    )
}
```

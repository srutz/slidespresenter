
# 3.8 Komponenten, Props und State / Zustandslose ("Stateless") versus zustandsabhängige ("Stateful") Komponenten 

- Komponente mit und ohne Zustand sind von außen nicht zu unterscheiden.
- Zustandslose Komponenten sind einfacher zu testen.
- Zustandslose Komponenten hängen nur von den übergebenen Props ab.

## Zustandslose Komponenten

- Ein Beispiel für eine Zustandslose Komponente ist ein Wrapper für eine Panel-Komponente mit TailwindCSS.

```typescript
import React from 'react';

interface PanelProps {
    children: React.ReactNode;
}

export function Panel({ children }: PanelProps) {
    return (
        <div className="bg-white shadow-md p-4">
            {children}
        </div>
    );
}
```

## Zustandsabhängige Komponenten

- Ein Beispiel für eine Zustandsabhängige Komponente ist ein Counter.

```typescript
import React, { useState } from 'react';

export function Counter() {
    const [count, setCount] = useState(0);

    return (
        <div>
            <button onClick={() => setCount(count + 1)}>Count : {count}</button>
        </div>
    );
}
```

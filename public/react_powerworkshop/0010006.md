
# 10.6 Routing mit React Router / Styling der ausgewählten, aktiven Route

- Die aktuelle Route kann mit der Klasse `active` gestylt werden.
- Diese Klasse wird automatisch von `react-router` hinzugefügt, wenn die Route aktiv ist.

```typescript
import { Link } from 'react-router';

export function Navigation() {
    return (
        <div>
            <h1>Navigation</h1>
            <ul>
                <li><Link to="/" className="active">Home</Link></li>
                <li><Link to="/about">About</Link></li>
                <li><Link to="/contact">Contact</Link></li>
            </ul>
        </div>
    )
}
```

- Die Klasse `active` kann dann im CSS gestylt werden:

```css
.active {
    color: red;
}
```

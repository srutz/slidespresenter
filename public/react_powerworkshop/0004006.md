# 4.6 Styling mit Tailwind CSS / Dynamische Klassen und Conditional Styling

## Tailwind scannt statisch

- Tailwind durchsucht den Quelltext nach vollständigen Klassennamen als Text, es führt keinen Code aus
- Zusammengesetzte Klassennamen werden daher nicht erkannt und es entsteht kein CSS:

```typescript
// FALSCH: "bg-red-500" kommt nirgends als vollständiger String vor
<div className={`bg-${color}-500`} />

// FALSCH: Template-String mit Teilnamen
<p className={`text-${size}`} />
```

- Richtig: immer vollständige Klassennamen im Quelltext notieren

```typescript
// RICHTIG: beide Klassen stehen vollständig im Code
<div className={isError ? 'bg-red-500' : 'bg-green-500'} />
```

## Lookup-Objekte für Varianten

- Für mehrere Varianten eines Props wird ein Objekt mit vollständigen Klassen verwendet
- `Record<Variant, string>` stellt sicher, dass alle Varianten abgedeckt sind

```typescript
type Variant = 'primary' | 'secondary' | 'danger'

const variantClasses: Record<Variant, string> = {
  primary: 'bg-blue-600 text-white hover:bg-blue-700',
  secondary: 'bg-slate-200 text-slate-900 hover:bg-slate-300',
  danger: 'bg-red-600 text-white hover:bg-red-700',
}

export function Button({ variant = 'primary', children }: {
  variant?: Variant
  children: React.ReactNode
}) {
  return <button className={`rounded-lg px-4 py-2 ${variantClasses[variant]}`}>{children}</button>
}
```

## clsx und tailwind-merge

- `clsx` baut Klassenlisten aus Bedingungen, Arrays und Objekten (Installation siehe Kapitel 2)
- `tailwind-merge` löst Konflikte auf: bei `p-2 p-4` gewinnt die letzte Klasse
- Die Hilfsfunktion `cn()` kombiniert beides:

```typescript
import { clsx, type ClassValue } from 'clsx'
import { twMerge } from 'tailwind-merge'

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

```typescript
<li className={cn(
  'rounded px-3 py-2',
  isActive && 'bg-blue-600 text-white',
  isDisabled && 'opacity-50',
  className, // von außen übergeben, überschreibt Defaults
)}>
```

- Für Komponenten mit vielen Varianten-Kombinationen gibt es `class-variance-authority` (cva) als Ergänzung

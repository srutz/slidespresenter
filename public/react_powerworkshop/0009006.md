# 9.6 HTTP, APIs und Server State / Abbrechen von Requests mit AbortController

## Warum Requests abbrechen?

- Eine Komponente wird ausgeblendet oder die Eingabe ändert sich, während der Request noch läuft.
- Die späte Antwort würde veralteten State setzen oder Bandbreite verschwenden.
- **Race Condition**: Request A (langsam) und Request B (schnell) werden nacheinander gestartet, A kommt zuletzt an und überschreibt das aktuellere Ergebnis von B.
- Lösung: den veralteten Request abbrechen. Das Web-Standard-API dafür ist der `AbortController`.

```typescript
const controller = new AbortController()

fetch('https://dummyjson.com/todos', { signal: controller.signal })

controller.abort() // das Promise wird mit einem AbortError abgelehnt
```

## Cleanup in useEffect

```typescript
import { useEffect, useState } from 'react'

export function TodoSearch({ query }: { query: string }) {
    const [todos, setTodos] = useState<Todo[]>([])

    useEffect(() => {
        const controller = new AbortController()

        async function load() {
            try {
                const res = await fetch(
                    `https://dummyjson.com/todos/search?q=${encodeURIComponent(query)}`,
                    { signal: controller.signal }
                )
                const json = await res.json()
                setTodos(json.todos)
            } catch (e) {
                if (e instanceof DOMException && e.name === 'AbortError') return
                console.error(e)
            }
        }
        load()

        return () => controller.abort() // Cleanup: läuft vor dem nächsten Effekt und beim Unmount
    }, [query])

    return <ul>{todos.map(t => <li key={t.id}>{t.todo}</li>)}</ul>
}
```

## Hinweise

- Ein abgebrochener Request wirft einen `AbortError`. Das ist kein echter Fehler und sollte nicht als Fehlermeldung angezeigt werden.
- In React Strict Mode (Entwicklung) wird jeder Effekt einmal zusätzlich gestartet und aufgeräumt: der erste Request wird abgebrochen, genau dafür ist das Cleanup da.
- Jeder Effekt-Durchlauf erzeugt einen eigenen Controller, ein Controller kann nur einmal abbrechen.
- Auch Axios akzeptiert `{ signal: controller.signal }`.
- TanStack Query übergibt `queryFn` ein `signal`, das beim Entfernen oder Ersetzen einer Query abgebrochen werden kann: `queryFn: ({ signal }) => fetch(url, { signal })`.

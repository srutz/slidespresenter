
# 7.10 Hooks und moderne React Patterns / Verwenden von "useMemo()"

## useMemo

- `useMemo` memoiziert das **Ergebnis einer Berechnung** — die Berechnung wird nur dann erneut ausgeführt, wenn sich die Abhängigkeiten ändern.
- Geeignet für:
  - aufwändige Berechnungen, die nicht bei jedem Render wiederholt werden sollen
  - stabile Objekt-/Array-Referenzen, die sonst `React.memo`-Kinder oder `useEffect`-Deps unnötig triggern würden

```typescript
import { useMemo, useState } from 'react'

const numbers = Array.from({ length: 100_000 }, (_, i) => i + 1)

export function PrimeList() {
    const [filter, setFilter] = useState('')

    const primes = useMemo(() => {
        return numbers.filter(n => {
            for (let i = 2; i <= Math.sqrt(n); i++) {
                if (n % i === 0) return false
            }
            return n > 1
        })
    }, [])

    return (
        <div>
            <input value={filter} onChange={e => setFilter(e.target.value)} placeholder="Suche..." />
            <ul>{primes.slice(0, 10).map(p => <li key={p}>{p}</li>)}</ul>
        </div>
    )
}
```

## useMemo — stabile Referenzen

- Objekte und Arrays werden in JavaScript bei jedem Render neu erstellt — auch wenn ihr Inhalt gleich bleibt.
- Das kann dazu führen, dass `React.memo`-Kinder oder `useEffect` unnötig feuern.

```typescript
import { memo, useMemo, useState } from 'react'

const UserCard = memo(({ user }: { user: { name: string; age: number } }) => {
    console.log('UserCard gerendert')
    return <div>{user.name} ({user.age})</div>
})

export function App() {
    const [count, setCount] = useState(0)

    const user = useMemo(() => ({ name: 'Alice', age: 30 }), [])

    return (
        <div>
            <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>
            <UserCard user={user} />
        </div>
    )
}
```

## useMemo — Wann einsetzen?

- `useMemo` ist wie `useCallback` eine **reine Optimierung** — der Code muss auch ohne funktionieren.

| Situation | useMemo sinnvoll? |
|-----------|------------------|
| Aufwändige Berechnung (> ~1ms) | ✅ Ja |
| Stabiles Objekt/Array für `React.memo`-Kind | ✅ Ja |
| Stabiles Objekt/Array für `useEffect`-Deps | ✅ Ja |
| Einfache Berechnung (Addition, String-Format) | ❌ Nein |

- Faustregel: zuerst ohne messen, dann erst optimieren.
- Der **React Compiler** (React 19+) übernimmt diese Memoizierung automatisch.

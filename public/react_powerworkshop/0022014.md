
# 22.14 SemVer und npm (Zusatzthema) / npm update

## Abhängigkeiten innerhalb der Range aktualisieren

```bash
npm update              # alle Pakete auf "Wanted" aktualisieren
npm update react        # nur ein bestimmtes Paket
```

- Aktualisiert installierte Pakete auf die neueste Version, die noch innerhalb der in `package.json` festgelegten Range (`^`, `~`, ...) liegt.
- Aktualisiert dabei auch `package-lock.json`.
- **Ändert `package.json` selbst nicht** (außer bei sehr neuen npm-Versionen mit `--save`, was aber unüblich ist).

## Wichtige Einschränkung

- `npm update` macht **keine** Major-Updates, selbst wenn `npm outdated` unter "Latest" eine neuere Hauptversion anzeigt - das würde ja laut SemVer potenziell brechende Änderungen bedeuten.
- Für ein Major-Update ist ein bewusster, manueller Schritt nötig, z. B. `npm install react@latest`.

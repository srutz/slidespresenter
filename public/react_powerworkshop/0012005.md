# 12.5 State Management mit Zustand / Zustand: Selektoren und gezielte Subscriptions

## Selektoren steuern Re-Renders

- Der Selektor bestimmt, welchen Teil des Stores eine Komponente abonniert.
- Zustand vergleicht das Ergebnis mit `Object.is`. Nur bei Änderung rendert die Komponente neu.

```typescript
// Gut: rendert nur, wenn sich count ändert
const count = useCounterStore((state) => state.count)

// Gut: Actions sind stabile Referenzen
const increment = useCounterStore((state) => state.increment)

// Abgeleitete Werte als primitiver Wert
const openCount = useTodoStore((state) => state.todos.filter((t) => !t.done).length)
```

## Anti-Pattern: ganzen Store abonnieren

```typescript
// Schlecht: rendert bei JEDER Änderung irgendeines Felds
const store = useTodoStore()
const { todos, addTodo } = useTodoStore()
```

## Mehrere Werte mit useShallow

- Ein Selektor, der ein **neues** Objekt oder Array liefert, ist bei jedem Aufruf "anders". In Zustand 5 führt das zu einer Endlosschleife ("Maximum update depth exceeded").
- `useShallow` vergleicht das Ergebnis flach (Elemente bzw. Properties) und stabilisiert die Referenz.

```typescript
import { useShallow } from 'zustand/react/shallow'

// Objekt mit mehreren Werten
const { todos, filter } = useTodoStore(
    useShallow((state) => ({ todos: state.todos, filter: state.filter }))
)

// Array (Tuple)
const [todos, addTodo] = useTodoStore(
    useShallow((state) => [state.todos, state.addTodo])
)

// Ohne useShallow: neue Referenz bei jedem Render
// const { todos, filter } = useTodoStore((s) => ({ todos: s.todos, filter: s.filter }))
```

## Custom Selector Hooks

- Den Store nicht exportieren, sondern kleine Hooks pro Anwendungsfall: einheitlich, testbar, Implementierung austauschbar.
- Actions können in einem eigenen Hook gebündelt werden (stabil, daher ohne `useShallow` möglich).

```typescript
const useTodoStore = create<TodoStore>()((set) => ({ /* ... */ }))

export const useTodos = () => useTodoStore((s) => s.todos)
export const useOpenTodoCount = () =>
    useTodoStore((s) => s.todos.filter((t) => !t.done).length)

export const useTodoActions = () =>
    useTodoStore(
        useShallow((s) => ({ addTodo: s.addTodo, toggleTodo: s.toggleTodo, removeTodo: s.removeTodo }))
    )

// Verwendung
const todos = useTodos()
const { addTodo } = useTodoActions()
```


# 3.6 Komponenten, Props und State / Manipulation von Zuständen

## React und State

- React Komponenten können ihren Zustand (state) verwalten.
- (Nur) Beim Ändern eines Zustands wird die Komponente neu gerendert.
- Zustände sind mit der Komponenteninstanz verknüpft.
- React schreibt die Aufrufe von useState() in der Reihenfolge mit, in der sie aufgerufen werden 
und ordnet diese Zustände der aktuell durchlaufenen Komponente zu.

# 3.6 Komponenten, Props und State / Manipulation von Zuständen

## React und useState

- `useState()` ist eine Funktion, die es ermöglicht, Zustände in Funktionskomponenten zu verwenden.
- Alle Funktionen die mit `use` beginnen, sind sogenannte Hooks.

- "Hello-World" Beispiel: "Counter"

```typescript
import { useState } from 'react';

export function Counter() {
    const [count, setCount] = useState(0)
    return (
        <div>
            <button onClick={() => setCount(count + 1)}>Count : {count}</button>
        </div>
    )
}
```


# 22.18 SemVer und npm (Zusatzthema) / npm dedupe

## Doppelte Versionen zusammenführen

```bash
npm dedupe
```

- Wenn zwei Pakete kompatible, aber unterschiedlich genau spezifizierte Versionen derselben Abhängigkeit verlangen, kann npm sie manchmal auf eine gemeinsame Version zusammenführen.
- Reduziert die Größe von `node_modules` und die Anzahl an doppelt geladenem Code im Bundle.
- Funktioniert nur innerhalb dessen, was die jeweiligen SemVer-Ranges erlauben - `npm dedupe` erzwingt keine inkompatiblen Versionen.
- Wird oft automatisch als Teil von `npm install` mit ausgeführt, kann aber auch gezielt einzeln aufgerufen werden.

- Reicht `npm dedupe` nicht aus, weil die Ranges sich tatsächlich widersprechen, hilft nur noch `overrides` (siehe folgende Folie).

# 4.13 Styling mit Tailwind CSS / Einordnung: CSS Modules und CSS-in-JS

## CSS Modules

- Eine Datei `Button.module.css` wird importiert, Klassennamen werden beim Build automatisch eindeutig gemacht
- Vite unterstützt CSS Modules ohne zusätzliche Konfiguration

```css
/* Button.module.css */
.button { padding: 0.5rem 1rem; border-radius: 0.5rem; }
.primary { background: royalblue; color: white; }
```

```typescript
import styles from './Button.module.css'

export function Button() {
  return <button className={`${styles.button} ${styles.primary}`}>Klick</button>
}
```

- Sinnvoll in Bestandsprojekten oder wenn Teams bewusst klassisches CSS schreiben wollen
- Lässt sich mit Tailwind mischen, im Neuprojekt aber meist unnötig

## CSS-in-JS: Emotion und Styled Components

- Styles werden in JavaScript/TypeScript geschrieben und zur Laufzeit als CSS in die Seite eingefügt

```typescript
import styled from 'styled-components'

const Button = styled.button<{ $primary?: boolean }>`
  padding: 0.5rem 1rem;
  background: ${(p) => (p.$primary ? 'royalblue' : 'lightgray')};
`
```

- Nachteile: Laufzeitkosten, schwierige Integration mit React Server Components und Streaming, Wartungsstatus einzelner Bibliotheken
- Für neue Projekte im Seminar-Stack nicht empfohlen, aber in vielen Bestandsprojekten anzutreffen
- Details, Migration und moderne Alternativen: siehe Kapitel 17 "Legacy- und Überblicksthemen"

## Entscheidungshilfe

| Ansatz | Einsatz |
|--------|---------|
| Tailwind CSS | Standard für neue Projekte im Seminar-Stack |
| Inline Styles | Einzelne dynamische Werte, z.B. berechnete Breite oder CSS-Variable |
| CSS Modules | Bestandsprojekte, Teams mit klassischem CSS |
| Globales CSS | Reset, Basis-Typografie, Theme-Variablen |
| Emotion / Styled Components | Nur Bestandsprojekte, siehe Kapitel 17 |

- Dynamische Werte, die nicht als Klasse vorab bekannt sind, werden per Inline-Style oder CSS-Variable übergeben:

```typescript
<div className="w-(--progress) h-2 bg-blue-600" style={{ '--progress': `${percent}%` } as React.CSSProperties} />
```

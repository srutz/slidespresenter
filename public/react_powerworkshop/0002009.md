## Fallunterscheidung in JSX

- Fallunterscheidungen können in JSX mit dem ternären Operator durchgeführt werden.

## Beispiel

```typescript
import { CSSProperties } from 'react';
type BigTextProps = {
    style: CSSProperties,
    children: string
}
export function BigText(props : BigTextProps) {
    const {style = {fontSize: 20}, children} = props
    return <div style={style}>{children.length > 10 ? children : 'Text zu kurz'}</div>;
}
```

## Schleifen in JSX

- Schleifen können in JSX mit der `map`-Funktion durchgeführt werden.

## Beispiel

```typescript
import { CSSProperties } from 'react';
type BigTextProps = {
    style: CSSProperties,
    children: string[]
}
export function BigText(props : BigTextProps) {
    const {style = {fontSize: 20}, children} = props
    return <div style={style}>{children.map((child, index) => <span key={index}>{child}</span>)}</div>;
}
```

## Kommentare in JSX

- Kommentare in JSX werden in geschweiften Klammern geschrieben.
- Man wechselt von JSX in JavaScript und schreibt den Kommentar entweder mit `/* */` oder `//` bis zum Zeilenende.

```html
<div>
     { /* Kommentar */ }
    <span>Text</span>
</div>
```

## JSX-Zusammenfassung 

- JSX ist fast wie HTML. Folgende wichtige Unterschiede existieren:
  - {} geschweifte Klammern erlauben direktes Einbetten von JavaScript/TypeScript.
  - CamelCase-Schreibweise für Attribute. Groß-/Kleinschreibung ist NICHT egal (z. B. `onClick` anstelle von `onclick` oder `className` anstelle von `class`).
  - `className` anstelle von `class`, `htmlFor` anstelle von `for` (JavaScript-Keywords).
  - Events müssen JavaScript-Funktionen sein, kein beliebiger JavaScript-Ausdruck.
  - Styles werden als JavaScript-Objekte angegeben (z. B.: `<div style={{ color: 'red' }}>`).
  - Fallunterscheidungen und Schleifen sind möglich, aber nur als Ausdrücke, nicht als Statements.

# 13.11 Testing / Playwright für End-to-End-Tests

## Installation und Konfiguration

- Playwright steuert Chromium, Firefox und WebKit; Tests laufen parallel und isoliert (eigener Browser-Context pro Test).

```bash
npm init playwright@latest   # legt playwright.config.ts und tests/ an
npx playwright test          # Tests ausführen (headless)
npx playwright test --ui     # interaktiver UI-Modus
```

```typescript
// playwright.config.ts
import { defineConfig } from '@playwright/test'

export default defineConfig({
  testDir: './e2e',
  use: { baseURL: 'http://localhost:5173', trace: 'on-first-retry' },
  webServer: {
    command: 'npm run dev',
    url: 'http://localhost:5173',
    reuseExistingServer: !process.env.CI,
  },
})
```

# 13.11 Testing / Playwright: Erster Test

- Locators (`getByRole`, `getByLabel`, `getByText`) funktionieren wie bei RTL und sind die bevorzugte Wahl.
- Auto-Waiting: Playwright wartet vor Aktionen automatisch, bis das Element sichtbar, stabil und bedienbar ist.
- `expect` mit Web-First-Assertions wiederholt die Prüfung bis zum Timeout.

```typescript
import { test, expect } from '@playwright/test'

test('user can add a todo', async ({ page }) => {
  await page.goto('/')

  await page.getByLabel('Neue Aufgabe').fill('Playwright lernen')
  await page.getByRole('button', { name: 'Hinzufügen' }).click()

  await expect(page.getByRole('listitem')).toHaveText('Playwright lernen')
  await expect(page).toHaveURL('/')
})
```

# 13.11 Testing / Playwright: Werkzeuge zur Fehlersuche

- Codegen zeichnet Interaktionen auf und erzeugt Testcode mit passenden Locators:

```bash
npx playwright codegen http://localhost:5173
```

- Trace Viewer: Zeitleiste mit Screenshots, DOM-Snapshots, Netzwerk und Konsole für jeden Schritt.

```bash
npx playwright test --trace on
npx playwright show-trace test-results/<test>/trace.zip
npx playwright show-report
```

- Debuggen: `npx playwright test --debug` oder `await page.pause()`.
- Netzwerk kann mit `page.route()` gemockt werden; für echte E2E-Tests besser gegen ein Testbackend laufen lassen.

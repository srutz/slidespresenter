
# Next.js Topics

- Next.js unterstützt sowohl Server-Side-Rendering (SSR) als auch React-Server-Components (RSC).
- Außerdem kann Next.js auch statische Seiten mittels der Static-Site-Generation (SSG) generieren.

- SSR und RSC sind zwei verschiedene Ansätze zur Generierung von React-Webseiten auf der Server-Seite.

# Next.js Topics / SSR

- SSR rendert die Seite auf dem Server und sendet sie an den Client. Dabei ist der Code der Componente der normale Code einer React-Komponente und wird ebenfalls im Browser ausgeführt.
- `useState` ist sinnvoll verwendbar, aber es wird nur der initiale Wert zurückgegeben. 
- `useContext` ist ebenfalls sinnvoll verwendbar, aber es wird nur der initiale Wert zurückgegeben.
- `useEffect` wird nicht auf dem Server ausgeführt, sondern nur im Browser.

# Next.js Topics / SSR und Hydration

- Hydration ist der Prozess, bei dem der Server den initialen HTML-Code an den Client sendet und der Client dann den Code mit React "hydratisiert", d.h. die React-Logik anwendet.
- Bei Abweichungen zwischen dem Server- und dem Client-Code kann es zu Hydration-Fehlern kommen. Folgende Gründe können Hydration-Fehler verursachen:
  
```
- A server/client branch `if (typeof window !== 'undefined')`.
- Variable input such as `Date.now()` or `Math.random()` which changes each time it's called.
- Date formatting in a user's locale which doesn't match the server. eg: new Intl.NumberFormat().format(123.456);
- Invalid HTML tag nesting. eg: <p><div>some words</div></p>
```


# Next.js Topics / RSC

- RSC sind React Server Components und werden auf dem Server ausgeführt. Die Ausführung erfolgt ausschließlich auf dem Server und nicht im Browser.
- RSC können keine Hooks verwenden.
- RSC können direkt auf Datenbanken und anderen Server-Ressourcen zugreifen. 
- RSC können async deklariert sein und async/await verwenden.

- Als Direktive können RSC `use` verwenden um Daten zu laden.
- Promises können in RSC erzeugt werden und an Client-Components als Props übergeben werden. 
- Diese Promises können dann mittels `use()` in Client-Components verwendet werden.

Beispiel:
[https://github.com/srutz/nextempty/tree/pass_promiserprops](https://github.com/srutz/nextempty/tree/pass_promiserprops)

# Next.js Topics / RSC und State-Management

- State-Management ist begrenzt auf Client-Components.
- RSC haben "by-design" keinen Zustand. 
- RSC sind nicht interaktiv



# Next.js Topics / Suspense

- Suspense ist eine React-Funktion, die es ermöglicht, Komponenten zu "sperren", während sie auf Daten warten.
- Suspense kann in RSC verwendet werden, um Daten zu laden und die UI zu sperren, bis die Daten geladen sind.

Beispiel:

[https://github.com/srutz/nextempty/tree/suspense](https://github.com/srutz/nextempty/tree/suspense)

# 4.3 Styling mit Tailwind CSS / Utility-First CSS: Grundkonzepte

## Spacing, Größen und Farben

- Spacing-Skala: eine Einheit entspricht `0.25rem` (`p-4` = 1rem, `p-2` = 0.5rem)
- Padding: `p-4`, `px-6` (horizontal), `py-2` (vertikal), `pt-1` (oben)
- Margin: `m-4`, `mx-auto` (zentrieren), `mt-8`, `-mt-2` (negativ)
- Abstand zwischen Kindern: `space-y-2`, besser `gap-2` mit Flex/Grid
- Größen: `w-64`, `w-full`, `max-w-md`, `h-10`, `min-h-screen`
- Farben bestehen aus Name und Stufe: `text-slate-700`, `bg-blue-500`, `border-gray-300`
- Transparenz mit Slash-Syntax: `bg-black/50`

## Typografie, Borders und Schatten

- Schriftgröße: `text-sm`, `text-base`, `text-xl`, `text-3xl`
- Schriftstärke: `font-normal`, `font-medium`, `font-semibold`, `font-bold`
- Ausrichtung und Zeilen: `text-center`, `leading-6`, `tracking-wide`, `truncate`
- Rahmen: `border`, `border-2`, `border-slate-200`, `border-b`
- Rundungen: `rounded`, `rounded-lg`, `rounded-full`
- Schatten: `shadow-xs`, `shadow-md`, `shadow-xl`
- Ringe: `ring-1 ring-slate-200` (Rahmen ohne Layout-Einfluss)
- Beliebige Werte in eckigen Klammern: `w-[340px]`, `bg-[#1da1f2]`

## Beispiel: Card-Komponente

```typescript
type CardProps = { title: string; text: string }

export function Card({ title, text }: CardProps) {
  return (
    <div className="max-w-sm rounded-xl border border-slate-200 bg-white p-6 shadow-md">
      <h2 className="mb-2 text-xl font-semibold text-slate-900">{title}</h2>
      <p className="text-sm leading-6 text-slate-600">{text}</p>
      <button className="mt-4 rounded-lg bg-blue-600 px-4 py-2 text-sm font-medium text-white">
        Mehr erfahren
      </button>
    </div>
  )
}
```

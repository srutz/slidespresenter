# Agenda - React Powerworkshop

## Kapitel 01: Ziele und Erwartungen der Teilnehmenden
Klärung individueller Lernziele und Erwartungen, Überblick über Seminar, Beispielanwendung und Tech-Stack, Einrichtung der Entwicklungsumgebung

## Kapitel 02: React Einführung
Was ist React, Einordnung gegenüber Alternativen, Projektsetup mit Vite und React + TypeScript, Projektstruktur, Komponenten und JSX/TSX, React Developer Tools

## Kapitel 03: Komponenten, Props und State
Funktionskomponenten, dynamische Inhalte, Props, children und Composition, useState(), Event Handling, Controlled Components, Lifting State Up, Listen, Keys und bedingtes Rendern

## Kapitel 04: Styling mit Tailwind CSS
Tailwind CSS als Standard: Einrichtung in Vite, Utility-First, Responsive Design, Varianten, Conditional Styling, Flexbox/Grid, Dark Mode und Theme; Einordnung klassischer Stylesheets, CSS Modules und CSS-in-JS

## Kapitel 05: React-Komponenten im Detail
Projektstruktur, Presentational und Stateful Components, Composition statt Vererbung, useEffect() und wann nicht, Refs, Fragment, Context, Error Boundaries, Lazy Loading und Suspense, memo, React Compiler, Custom Hooks

## Kapitel 06: React mit TypeScript
TypeScript von Beginn an: Props, Events, Hooks, API-Daten, Union Types und Discriminated Unions, Type Inference, typische Patterns

## Kapitel 07: Hooks und moderne React Patterns
Rules of Hooks, useState/useEffect/useRef/useContext, useReducer, useMemo/useCallback, Custom Hooks, useTransition/useDeferredValue, use(), Actions, useOptimistic, Hook-Anti-Patterns

## Kapitel 08: useHooks als Standard-Hook-Sammlung
Praxiserprobte Standard-Hooks auswählen und einsetzen, vorhandenen Hook nutzen vs. eigenen entwickeln, externe Hooks bewerten

## Kapitel 09: HTTP, APIs und Server State
fetch und async/await, Loading-/Error-/Empty-States, AbortController, Axios-Einordnung, TanStack Query (Queries, Mutations, Invalidation, Optimistic Updates), Client State vs. Server State

## Kapitel 10: Routing mit React Router
Client-Side Routing, Link/NavLink, Parameter und Search Params, Nested/Layout Routes, Outlet, Redirects, 404, geschützte Bereiche, Lazy Loading, Data APIs

## Kapitel 11: Formulare und Validierung
Controlled/Uncontrolled Inputs, React Hook Form, Zod, Validierungsfeedback, serverseitige Fehler, wiederverwendbare Formular-Komponenten

## Kapitel 12: State Management mit Zustand
Arten von State, useState vs. Context vs. Store, Zustand (Stores, Selektoren, Immer, persist, DevTools), Zusammenspiel mit TanStack Query, Redux Toolkit als Einordnung

## Kapitel 13: Testing
Teststrategie, Vitest, React Testing Library, MSW, Hooks und Stores testen, Playwright für E2E, Tests in CI/CD

## Kapitel 14: Build, Deployment und Produktion
Vite Build, Environment Variables, Code Splitting, Bundle-Analyse, SPA-Hosting, Nginx und Docker, Cloud-Plattformen, CI/CD, Source Maps

## Kapitel 15: Best Practices und Architektur
Feature-basierte Struktur, Trennung von UI/Logik/API, Client vs. Server State, Prop Drilling, Fehlerbehandlung, Accessibility, Performance und Security, Anti-Patterns

## Kapitel 16: Seminar-Stack im Überblick
React + TypeScript + Vite, Tailwind CSS, React Router, Zustand, TanStack Query, React Hook Form + Zod, useHooks, Vitest + React Testing Library, Playwright

## Kapitel 17: Legacy- und Überblicksthemen
Create React App, Klassenkomponenten und Lifecycle, HOCs, contextType, klassisches Redux, Emotion und Styled Components

## Kapitel 18: React und Authentifizierung (Zusatzthema)
Authentifizierung in einer Single Page Application (SPA) - JWT

## Kapitel 19: Advanced React Topics (Zusatzthema)
React Patterns, React-Components mit externem State

## Kapitel 20: React 19 Topics (Zusatzthema)
React Compiler, Activity, ViewTransition

## Kapitel 21: Next.js Topics (Zusatzthema)
Server-Side-Rendering (SSR), React-Server-Components (RSC), Static-Site-Generation (SSG)

## Kapitel 22: SemVer und npm (Zusatzthema)
Semantic Versioning im Detail, dessen Einsatz jenseits von Node.js sowie npm-Werkzeuge zur Versionsverwaltung: package.json, package-lock.json, audit, update, outdated, ls, why, overrides

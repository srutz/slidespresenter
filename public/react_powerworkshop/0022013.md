
# 22.13 SemVer und npm (Zusatzthema) / npm outdated

## Veraltete Pakete erkennen

```bash
npm outdated
```

```
Package  Current  Wanted  Latest  Location
react      18.2.0  18.3.1  19.1.0  node_modules/react
vite        5.1.0   5.4.2   6.0.3  node_modules/vite
```

- **Current**: aktuell installierte Version.
- **Wanted**: neueste Version, die noch innerhalb der in `package.json` erlaubten Range liegt - das würde `npm update` installieren.
- **Latest**: die insgesamt neueste veröffentlichte Version, auch wenn sie außerhalb der erlaubten Range liegt (z. B. ein neues Major-Release).

- `npm outdated` verändert nichts, es zeigt nur den Ist-Zustand - ideal, um vor einem Update einen Überblick zu bekommen, insbesondere über anstehende Major-Upgrades (Current ≠ Wanted ≠ Latest).

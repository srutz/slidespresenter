# 15.3 Best Practices und Architektur / Wiederverwendbare Komponenten und Custom Hooks

## Wann extrahieren?

- Regel der drei: Beim ersten Mal schreiben, beim zweiten Mal dulden, beim dritten Mal extrahieren.
- Zu frühe Abstraktion ist teurer als etwas Duplikation: falsche Abstraktionen sammeln Flags und Sonderfälle.
- Extrahieren ist sinnvoll, wenn
    - ein Stück UI an mehreren Stellen identisch ist,
    - eine Komponente mehrere Aufgaben hat und schwer lesbar wird,
    - Logik getrennt testbar sein soll.
- Aufteilung: Komponenten für Darstellung, Custom Hooks (Kapitel 7) für Logik mit State und Effects.

# 15.3 Best Practices und Architektur / API-Design von Komponenten

- Wenige, klar benannte Props; Typen über TypeScript (Kapitel 6) erzwingen.
- Statt vieler Boolean-Flags lieber Varianten (`variant="primary"`) oder Composition mit `children`.
- Native HTML-Props durchreichen, damit `aria-*`, `onClick` und `className` funktionieren.
- Styling mit Tailwind (Kapitel 4): `className` zusätzlich zulassen, nicht überall eigene Props für Farben erfinden.

```typescript
type ButtonProps = React.ComponentProps<'button'> & {
    variant?: 'primary' | 'secondary'
}

export function Button({ variant = 'primary', className = '', ...rest }: ButtonProps) {
    const base = 'rounded px-3 py-1 font-medium'
    const colors = variant === 'primary' ? 'bg-blue-600 text-white' : 'bg-gray-200'
    return <button className={`${base} ${colors} ${className}`} {...rest} />
}
```

# 15.3 Best Practices und Architektur / Custom Hooks gezielt einsetzen

- Ein Hook kapselt eine Sache und hat einen sprechenden Namen (`useTodos`, `useDebouncedValue`).
- Rückgabe: ein Objekt mit benannten Werten, wenn es mehr als zwei sind.
- Fertige Hooks prüfen, bevor man eigene schreibt (useHooks, Kapitel 8).
- Ein Hook ohne eigenen State oder Effect ist meist nur eine Funktion und braucht kein `use`.

```typescript
export function useDebouncedValue<T>(value: T, delay = 300) {
    const [debounced, setDebounced] = useState(value)
    useEffect(() => {
        const id = setTimeout(() => setDebounced(value), delay)
        return () => clearTimeout(id)
    }, [value, delay])
    return debounced
}
```

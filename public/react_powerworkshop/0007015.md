
# 7.15 Hooks und moderne React Patterns / Verwenden von "useTransition()"

## useTransition

- `useTransition` markiert State-Updates als **nicht dringlich** — React kann damit dringlichere Updates (z. B. Tastatureingaben) priorisieren und die UI reaktionsfähig halten.
- Gibt `[isPending, startTransition]` zurück:
  - `isPending`: `true` während das Transition-Update noch verarbeitet wird
  - `startTransition`: Funktion, in die man das nicht-dringende Update einwickelt

```typescript
import { useState, useTransition } from 'react'

export function SearchPage() {
    const [query, setQuery] = useState('')
    const [results, setResults] = useState<string[]>([])
    const [isPending, startTransition] = useTransition()

    function handleChange(e: React.ChangeEvent<HTMLInputElement>) {
        setQuery(e.target.value)
        startTransition(() => {
            setResults(heavySearch(e.target.value))
        })
    }

    return (
        <div>
            <input value={query} onChange={handleChange} />
            {isPending ? <p>Suche läuft...</p> : <ResultList results={results} />}
        </div>
    )
}
```

## useTransition — Tab-Wechsel-Beispiel

```typescript
import { memo, useState, useTransition } from 'react'

const tabs = ['Übersicht', 'Details', 'Bewertungen']

export function TabbedView() {
    const [activeTab, setActiveTab] = useState(tabs[0])
    const [isPending, startTransition] = useTransition()

    return (
        <div>
            <div>
                {tabs.map(tab => (
                    <button
                        key={tab}
                        onClick={() => startTransition(() => setActiveTab(tab))}
                        style={{ fontWeight: activeTab === tab ? 'bold' : 'normal' }}
                    >
                        {tab}
                    </button>
                ))}
            </div>
            {isPending && <p style={{ opacity: 0.5 }}>Laden...</p>}
            <SlowTabContent tab={activeTab} />
        </div>
    )
}
```

## useTransition — Wann einsetzen?

- `useTransition` eignet sich für State-Updates, die eine **aufwändige Re-Render-Kaskade** auslösen — z. B. große Listen filtern, Tab-Inhalte wechseln, Suchergebnisse rendern.

| Situation | useTransition sinnvoll? |
|-----------|------------------------|
| Große Liste filtern/sortieren | ✅ Ja |
| Tab-Wechsel mit schwerem Inhalt | ✅ Ja |
| Navigation zu einer neuen Ansicht | ✅ Ja |
| Einfaches Toggle (Boolean) | ❌ Nein |
| Input-Wert selbst aktualisieren | ❌ Nein (immer dringend) |

- Verwandt: `useDeferredValue` — memoiziert einen Wert und aktualisiert ihn verzögert (Alternative wenn man kein eigenes State-Update auslöst).

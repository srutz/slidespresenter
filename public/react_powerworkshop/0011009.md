
# 11.9 Formulare und Validierung / Datei-Upload

## Datei-Upload mit `<input type="file">`

- File-Inputs sind **unkontrolliert** — React kann den Wert nicht per `value` setzen (Sicherheitsregel des Browsers).
- Die ausgewählte Datei liegt in `event.target.files[0]` als `File`-Objekt.
- Zum Hochladen wird ein `FormData`-Objekt an `fetch` übergeben — kein JSON.

```typescript
import { useState } from 'react'

export function FileUpload() {
    const [file, setFile] = useState<File | null>(null)
    const [status, setStatus] = useState('')

    const handleSubmit = async (e: React.FormEvent) => {
        e.preventDefault()
        if (!file) return
        const body = new FormData()
        body.append('file', file)
        setStatus('Lädt hoch…')
        const res = await fetch('/api/upload', { method: 'POST', body })
        setStatus(res.ok ? 'Fertig!' : 'Fehler beim Upload')
    }

    return (
        <form onSubmit={handleSubmit}>
            <input
                type="file"
                onChange={(e) => setFile(e.target.files?.[0] ?? null)}
            />
            {file && <p>{file.name} ({(file.size / 1024).toFixed(1)} KB)</p>}
            <button type="submit" disabled={!file}>Hochladen</button>
            {status && <p>{status}</p>}
        </form>
    )
}
```

## Datei-Vorschau (Bild)

- Mit `URL.createObjectURL(file)` lässt sich eine temporäre lokale URL erzeugen — kein Server nötig.
- Diese URL sollte mit `URL.revokeObjectURL` wieder freigegeben werden, wenn sie nicht mehr gebraucht wird.

```typescript
import { useState, useEffect } from 'react'

export function ImagePreview() {
    const [file, setFile] = useState<File | null>(null)
    const [preview, setPreview] = useState<string | null>(null)

    useEffect(() => {
        if (!file) { setPreview(null); return }
        const url = URL.createObjectURL(file)
        setPreview(url)
        return () => URL.revokeObjectURL(url)
    }, [file])

    return (
        <div>
            <input
                type="file"
                accept="image/*"
                onChange={(e) => setFile(e.target.files?.[0] ?? null)}
            />
            {preview && (
                <img src={preview} alt="Vorschau" style={{ maxWidth: 300, marginTop: 8 }} />
            )}
        </div>
    )
}
```

## Drag & Drop Upload

- HTML5 Drag & Drop: `onDragOver` (Standardverhalten verhindern) + `onDrop` zum Empfangen der Datei.
- Die Datei liegt in `event.dataTransfer.files[0]` — gleicher Typ wie bei `input[type=file]`.
- Optisch: mit State tracken, ob die Datei gerade über dem Bereich schwebt (`isDragging`).

```typescript
export function DropZone() {
    const [file, setFile] = useState<File | null>(null)
    const [isDragging, setIsDragging] = useState(false)

    const handleDrop = (e: React.DragEvent) => {
        e.preventDefault()
        setIsDragging(false)
        const dropped = e.dataTransfer.files[0]
        if (dropped) setFile(dropped)
    }

    return (
        <div
            onDragOver={(e) => { e.preventDefault(); setIsDragging(true) }}
            onDragLeave={() => setIsDragging(false)}
            onDrop={handleDrop}
            style={{
                border: `2px dashed ${isDragging ? 'blue' : '#ccc'}`,
                padding: 32,
                textAlign: 'center',
                background: isDragging ? '#eef' : 'white',
            }}
        >
            {file ? file.name : 'Datei hierher ziehen'}
        </div>
    )
}
```

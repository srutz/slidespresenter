
# 7.8 Hooks und moderne React Patterns / Verwenden von "useCallback()"

## useCallback und die Verwendung von Memoization

- `useCallback` ist ein Hook, der die Memoization von Funktionen in Funktionskomponenten ermöglicht
- Memoization ist eine Technik, um die Ausführung von Funktionen zu speichern und bei erneutem Aufruf die gespeicherten Werte zurückzugeben
- Außerdem können Stale-Closures vermieden werden, indem man die Werte auf die die Funktionen zugreifen in das Array der Abhängigkeiten schreibt

```typescript
import { useCallback, useState } from 'react'

export function Counter() {
    const [count, setCount] = useState(0)
    const increment = useCallback(() => setCount(count + 1), [count])
    return (
        <div>
            <button onClick={increment}>Count : {count}</button>
        </div>
    )
}
```


# 22.16 SemVer und npm (Zusatzthema) / npm ls

## Den Abhängigkeitsbaum anzeigen

```bash
npm ls              # eigene direkte Dependencies, eine Ebene tief
npm ls --all        # kompletter Baum, beliebig tief
npm ls react        # nur Vorkommen eines bestimmten Pakets, mit vollem Pfad
npm ls --depth=2    # bis zu einer bestimmten Tiefe
```

```
meine-app@1.4.2
├── react@18.3.1
├─┬ some-ui-lib@2.0.0
│ └── react@17.0.2   <-- doppelte, ältere Version!
└── vite@6.0.3
```

- Besonders nützlich, um **doppelt installierte Versionen** eines Pakets zu finden (häufige Ursache für "funktioniert lokal, aber nicht gebündelt"-Fehler oder unerwartet große Bundle-Größen).
- Mit `npm ls react` sieht man sofort, welche Pakete jeweils welche Version von `react` verlangen.


# 4.12 Styling mit Tailwind CSS / Stile und Klassen dynamisch erstellen und nutzen

## Dynamische Styles

- Die Styles können natürlich auch dynamisch in Abhängigkeit von Props oder State erstellt werden.
- Hier ein Beispiel, bei dem die Schriftgröße abhängig von einem Zustand ist:

```typescript
import { useState } from 'react';

export function DynamicStyle() {
    const [fontSize, setFontSize] = useState(20)
    const style = {
        fontSize: fontSize
    }
    console.log("rendering mit fontSize: ", fontSize)
    return (
        <div>
            <h1 style={style}>Meine Komponente</h1>
            <button onClick={() => setFontSize(fontSize + 1)}>Größe erhöhen</button>
        </div>
    )
}
```

- Tipp: Mittels console.log das Rerendern der Komponente beobachten.

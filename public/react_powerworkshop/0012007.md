
# 12.7 State Management mit Zustand / Zustand mit localStorage-Middleware

## persist – automatisches Speichern im localStorage

- Zustand bringt eine eingebaute `persist`-Middleware mit.
- Der Store wird automatisch in `localStorage` (oder `sessionStorage`) gespeichert und beim nächsten Seitenaufruf wiederhergestellt.
- Kein eigenes `useEffect` oder manuelles Serialisieren nötig.

```typescript
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

type CounterStore = {
    count: number
    increment: () => void
    decrement: () => void
    reset: () => void
}

export const useCounterStore = create<CounterStore>()(
    persist(
        (set) => ({
            count: 0,
            increment: () => set((state) => ({ count: state.count + 1 })),
            decrement: () => set((state) => ({ count: state.count - 1 })),
            reset: () => set({ count: 0 }),
        }),
        { name: 'counter-store' }   // localStorage-Key
    )
)
```

- `name` ist der Schlüssel im `localStorage` – muss eindeutig sein.
- Der Store wird bei jedem `set`-Aufruf automatisch gespeichert.
- Beim nächsten Laden wird der State aus dem `localStorage` wiederhergestellt.

# 12.7 State Management mit Zustand / Zustand – persist mit partialize

## Nur Teile des States persistieren

- Oft soll nicht der **gesamte** State gespeichert werden (z. B. keine Funktionen, kein UI-State).
- `partialize` bestimmt, welche Felder in den `localStorage` geschrieben werden.

```typescript
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

type SettingsStore = {
    theme: 'light' | 'dark'
    language: string
    sidebarOpen: boolean          // soll NICHT persistiert werden
    setTheme: (theme: 'light' | 'dark') => void
    setLanguage: (lang: string) => void
    setSidebarOpen: (open: boolean) => void
}

export const useSettingsStore = create<SettingsStore>()(
    persist(
        (set) => ({
            theme: 'light',
            language: 'de',
            sidebarOpen: false,
            setTheme: (theme) => set({ theme }),
            setLanguage: (language) => set({ language }),
            setSidebarOpen: (sidebarOpen) => set({ sidebarOpen }),
        }),
        {
            name: 'settings-store',
            partialize: (state) => ({
                theme: state.theme,
                language: state.language,
            }),
        }
    )
)
```

- `partialize` gibt an, welche Felder serialisiert werden – `sidebarOpen` wird hier absichtlich ausgelassen.
- Funktionen (`setTheme` etc.) werden sowieso nicht serialisiert und müssen nicht explizit ausgeschlossen werden.

# 12.7 State Management mit Zustand / Zustand – persist mit Immer kombinieren

## Kombination von persist und immer

- Middlewares können gestapelt werden – die Reihenfolge ist dabei wichtig: `persist` außen, `immer` innen.

```typescript
import { create } from 'zustand'
import { persist } from 'zustand/middleware'
import { immer } from 'zustand/middleware/immer'

type Todo = { id: number; text: string; done: boolean }

type TodoStore = {
    todos: Todo[]
    addTodo: (text: string) => void
    toggleTodo: (id: number) => void
}

let nextId = 1

export const useTodoStore = create<TodoStore>()(
    persist(
        immer((set) => ({
            todos: [],
            addTodo: (text) =>
                set((state) => {
                    state.todos.push({ id: nextId++, text, done: false })
                }),
            toggleTodo: (id) =>
                set((state) => {
                    const todo = state.todos.find((t) => t.id === id)
                    if (todo) todo.done = !todo.done
                }),
        })),
        { name: 'todo-store' }
    )
)
```

- Todos werden automatisch im `localStorage` unter dem Key `todo-store` gespeichert.
- Nach einem Seitenreload ist die Liste noch vorhanden.
- `immer` ermöglicht weiterhin die direkte Mutation im `set`-Callback.

## Wann Zustand statt Redux?

- Kleine bis mittlere Apps ohne komplexe Side-Effects → **Zustand**
- Große Teams, Redux DevTools, komplexe Middleware-Ketten → **Redux Toolkit**
- Einfach ausprobieren: Zustand ist in wenigen Minuten eingerichtet

# 5.13 React-Komponenten im Detail / Custom Hooks zur Wiederverwendung von Logik

## Custom Hooks

- Ein Custom Hook ist eine Funktion, deren Name mit use beginnt und die andere Hooks aufruft.
- Damit wird zustandsbehaftete Logik aus Komponenten extrahiert und wiederverwendet. Der State selbst ist pro Aufrufer getrennt.
- Das use-Präfix ist wichtig: Linter und Compiler erkennen daran, dass die Rules of Hooks gelten.
- Custom Hooks teilen Logik, nicht Darstellung (dafür: Composition, siehe 5.3).

## Beispiel: useToggle

```typescript
import { useState, useCallback } from 'react';

export function useToggle(initial = false) {
    const [value, setValue] = useState(initial)
    const toggle = useCallback(() => setValue(v => !v), [])
    return [value, toggle] as const
}

export function Details() {
    const [open, toggle] = useToggle()
    return (
        <div>
            <button onClick={toggle}>{open ? 'Weniger' : 'Mehr'}</button>
            {open && <p>Details ...</p>}
        </div>
    )
}
```

- Ausführlich: Kapitel 7 (Hooks und moderne React Patterns). Kapitel 8 (useHooks) bringt eine fertige Sammlung, in der useToggle bereits enthalten ist.


# React 19 Topics / Activity

- <Activity> ist das neue "Keepalive" von React19.

- Activities ist ein WrapperComponent dessen Inhalt sichtbar und unsichtbar gemacht werden kann.

- Es finden mount und unmount Events statt und ein Rendering im Hintergrund. Deswegen ist Activity leistungsfähiger als ein manuell implementierter Wrapper der die CSS-Klasse "hidden" setzt.

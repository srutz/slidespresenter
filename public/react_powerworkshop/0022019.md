
# 22.19 SemVer und npm (Zusatzthema) / overrides

## Wenn SemVer nicht ausreicht

- Manchmal verlangt eine tief verschachtelte, transitive Abhängigkeit eine Version, die man aus gutem Grund nicht will:
  - eine Version mit bekannter Sicherheitslücke, für die der Maintainer des Zwischenpakets noch kein Update veröffentlicht hat,
  - zwei Pakete verlangen inkompatible Major-Versionen derselben Bibliothek,
  - man möchte projektweit eine bestimmte Version erzwingen, unabhängig davon, was einzelne Pakete deklarieren.
- `npm update`, `npm dedupe` und normale Ranges können solche Konflikte nicht lösen, wenn sie sich gegenseitig ausschließen.
- Dafür gibt es seit npm 8.3 das Feld `overrides` in `package.json`.

# 22.19 SemVer und npm (Zusatzthema) / overrides - Syntax und Beispiel

## overrides in package.json

```json
{
  "overrides": {
    "some-old-lib": {
      "lodash": "4.17.21"
    },
    "react": "19.1.0"
  }
}
```

- Der erste Eintrag erzwingt `lodash@4.17.21` **nur** dort, wo `some-old-lib` es einbindet.
- Der zweite Eintrag (`"react": "19.1.0"`) erzwingt diese Version für **jedes** Paket im Baum, das `react` verlangt.
- `overrides` überschreibt gezielt, was transitive Pakete in ihrer eigenen `package.json` deklariert haben - man übernimmt damit aber auch die Verantwortung, dass die erzwungene Version tatsächlich funktioniert.

# 22.19 SemVer und npm (Zusatzthema) / overrides - Verwandte Mechanismen

## Ähnliche Konzepte in anderen Werkzeugen

- **Yarn**: kennt das äquivalente Feld `resolutions` (historisch der Vorreiter dieses Musters, von npm später mit `overrides` übernommen).
- **pnpm**: bietet ebenfalls `pnpm.overrides` in der `package.json`.
- Alle drei Mechanismen lösen dasselbe Problem: das gezielte, manuelle Aushebeln der von Paketen selbst deklarierten SemVer-Ranges für den gesamten Abhängigkeitsbaum.
- Faustregel: `overrides` sparsam und mit Kommentar/Ticket-Referenz einsetzen - es ist ein Workaround, kein Dauerzustand. Sobald das zugrunde liegende Paket aktualisiert wurde, sollte der Override wieder entfernt werden.

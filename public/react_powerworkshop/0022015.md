
# 22.15 SemVer und npm (Zusatzthema) / npm audit

## Sicherheitslücken finden

```bash
npm audit
```

- Gleicht alle installierten Pakete (auch transitive Abhängigkeiten) gegen eine Datenbank bekannter Sicherheitslücken ab.
- Gibt für jeden Fund den Schweregrad an: `low`, `moderate`, `high`, `critical`.
- Zeigt an, ab welcher Version die Lücke behoben ist und über welche Abhängigkeitskette das betroffene Paket eingebunden wird.

# 22.15 SemVer und npm (Zusatzthema) / npm audit fix

## Lücken automatisch schließen

```bash
npm audit fix          # sichere Fixes, respektiert bestehende Ranges
npm audit fix --force  # erlaubt auch Major-Updates / brechende Änderungen
```

- `npm audit fix` aktualisiert betroffene Pakete auf eine unkritische Version, soweit dies innerhalb der erlaubten SemVer-Range möglich ist.
- `--force` geht weiter und installiert nötigenfalls auch neue Major-Versionen - das kann die Anwendung brechen und sollte danach gründlich getestet werden.
- `npm audit` ist Teil einer guten CI-Pipeline, ersetzt aber keine echte Security-Review.

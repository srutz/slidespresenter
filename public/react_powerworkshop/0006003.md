
# 6.3 React mit TypeScript / Typisierung von Komponenten-Props und -Events mit TypeScript


## Typisierung von Props

- Props können inline oder als Interface oder Type-Alias definiert werden.

```typescript
interface PersonProps {
    name: string;
    age: number;
}

function Person({name, age}: PersonProps) {
    return (
        <div>
            <h1>{name}</h1>
            <p>{age}</p>
        </div>
    )
}
```

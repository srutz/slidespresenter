
# 12.14 State Management mit Zustand / "Subscriptions" hinzufügen

## Verwendung in der Komponente

- Durch die Verwendung von `useSelector` wird unsere Komponente reaktiv in Bezug auf Änderungen im Store.
- Reaktiv bedeutet, dass die Komponente automatisch neu gerendert wird, wenn sich der Wert im Store ändert.


# 6.4 React mit TypeScript / Typisierung von Event-Handlern mit TypeScript

## Typendeklarationen von Events

- Typendeklarationen von Events sind wichtig, um die Typsicherheit in React-Komponenten zu gewährleisten.

```typescript
import { MouseEvent } from 'react';

function handleClick(event: MouseEvent<HTMLButtonElement>) {
    console.log('Button clicked');
}
```

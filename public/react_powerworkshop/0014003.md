# 14.3 Build, Deployment und Produktion / Code Splitting und Lazy Loading im Build

## Chunks und dynamic import

- Ohne Splitting entsteht ein großes Bundle, das der Browser komplett laden muss, bevor etwas angezeigt wird.
- Ein dynamischer `import()` markiert eine Splitting-Grenze: Vite erzeugt daraus einen eigenen Chunk, der erst bei Bedarf geladen wird.
- Gemeinsam genutzter Code wird automatisch in gemeinsame Chunks ausgelagert.

```typescript
async function exportPdf() {
  const { generatePdf } = await import('./pdf/generatePdf')
  generatePdf()
}
```

- Die Ausgabe von `vite build` listet alle Chunks mit Größe (und gzip-Größe) auf.

# 14.3 Build, Deployment und Produktion / Route-basiertes Splitting

- Der übliche Schnitt: ein Chunk pro Route mit `React.lazy` und `Suspense`.

```typescript
import { lazy, Suspense } from 'react'
import { createBrowserRouter, RouterProvider } from 'react-router'

const Dashboard = lazy(() => import('./pages/Dashboard'))
const Settings = lazy(() => import('./pages/Settings'))

const router = createBrowserRouter([
  { path: '/', element: <Home /> },
  { path: '/dashboard', element: <Suspense fallback={<Spinner />}><Dashboard /></Suspense> },
  { path: '/settings', element: <Suspense fallback={<Spinner />}><Settings /></Suspense> },
])
```

- Die Komponente muss ein `default` Export sein.
- React Router bietet alternativ die Route-Eigenschaft `lazy: () => import('./pages/Settings')`.

# 14.3 Build, Deployment und Produktion / manualChunks und Preloading

- `manualChunks` gruppiert Bibliotheken, die sich selten ändern; sie bleiben im Browser-Cache, auch wenn sich der Anwendungscode ändert.

```typescript
// vite.config.ts
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          react: ['react', 'react-dom', 'react-router'],
        },
      },
    },
  },
})
```

- Vite fügt für Chunks des Einstiegs automatisch `<link rel="modulepreload">` ein.
- Für wahrscheinliche nächste Seiten: beim Hover über einen Link den Import anstoßen.

```typescript
const prefetchSettings = () => import('./pages/Settings')
// <Link to="/settings" onMouseEnter={prefetchSettings}>Settings</Link>
```

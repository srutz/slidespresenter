
# 17.4 Legacy- und Überblicksthemen / Übersicht über den Lebenszyklus von React-Komponenten

- React-Komponenten durchlaufen einen Lebenszyklus, der in verschiedene Phasen unterteilt ist.

1. **Initialisierung**: Die Komponente wird initialisiert und die Props werden gesetzt.
2. **Mounting**: Die Komponente wird in den DOM eingefügt.
3. **Updating**: Die Komponente wird aktualisiert, wenn sich der State ändert, ein Kontext sich ändert, oder die Eltern-Komponente neu gerendert wird.
4. **Unmounting**: Die Komponente wird aus dem DOM entfernt.

# 17.4 Legacy- und Überblicksthemen / Übersicht über den Lebenszyklus von React-Komponenten

## Lebenszyklus-Methoden

- In den Funktionskomponenten gibt es keine Lebenszyklus-Methoden wie `componentDidMount`, `componentDidUpdate` oder `componentWillUnmount`.
- Events wie componentDidMount, componentDidUpdate und componentWillUnmount können mit dem `useEffect`-Hook behandelt werden.

```typescript

import { useEffect } from 'react'

export function MyComponent() {
    useEffect(() => {
        // componentDidMount
        return () => {
            // componentWillUnmount
        }
    }, [])

    useEffect(() => {
        // componentDidUpdate (bei Änderung eines bestimmten Props)
        // Einzelne Prop-Werte als Abhängigkeiten angeben, nicht das ganze props-Objekt
    }, [/* props.someValue */])

    return <div>My Component</div>
}
```

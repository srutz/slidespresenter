
# 11.8 Formulare und Validierung / Select und Radio

## Select-Element (Dropdown)

- `<select>` wird wie ein kontrolliertes Texteingabe-Element behandelt: `value` + `onChange`.
- Der ausgewählte Wert liegt immer als String vor — bei Zahlen muss man manuell konvertieren.
- `<select multiple>` erlaubt Mehrfachauswahl; hier ist `value` ein Array von Strings.

```typescript
import { useState } from 'react'

export function SelectExample() {
    const [country, setCountry] = useState('de')

    return (
        <div>
            <label>Land</label>
            <select value={country} onChange={(e) => setCountry(e.target.value)}>
                <option value="de">Deutschland</option>
                <option value="at">Österreich</option>
                <option value="ch">Schweiz</option>
            </select>
            <p>Gewählt: {country}</p>
        </div>
    )
}
```

## Radio-Buttons

- Radio-Buttons sind eine Gruppe von Inputs mit dem gleichen `name`-Attribut.
- Jeder Button bekommt `checked={value === option}` und denselben `onChange`-Handler.
- Im Gegensatz zu Checkboxen ist immer genau **eine** Option aktiv.

```typescript
const SIZES = ['S', 'M', 'L', 'XL']

export function RadioExample() {
    const [size, setSize] = useState('M')

    return (
        <fieldset>
            <legend>Größe</legend>
            {SIZES.map(s => (
                <label key={s}>
                    <input
                        type="radio"
                        name="size"
                        value={s}
                        checked={size === s}
                        onChange={(e) => setSize(e.target.value)}
                    />
                    {s}
                </label>
            ))}
            <p>Gewählt: {size}</p>
        </fieldset>
    )
}
```


# 10.7 Routing mit React Router / Parameter an Routen übergeben und auswerten

- Mittels des Hooks `useParams()` können Parameter aus der URL ausgelesen werden (Werden in der Route mit `:` definiert).
- Die Query-Parameter können mittels des Hooks `useSearchParams()` ausgelesen werden.

```typescript
import { useParams, useSearchParams } from 'react-router';

export function About() {
    const params = useParams();
    const searchParams = useSearchParams();

    return (
        <div>
            <h1>About</h1>
            <p>Parameter: {JSON.stringify(params)}</p>
            <p>Query-Parameter: {JSON.stringify(searchParams)}</p>
        </div>
    )
}
```

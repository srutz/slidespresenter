# 8.1 useHooks als Standard-Hook-Sammlung / useHooks im Seminar

## Idee: vorhandenen Hook nutzen

- Viele Hooks wiederholen sich in jedem Projekt: Debounce, LocalStorage, Media Query, Click Outside
- Statt sie jedes Mal neu zu schreiben, nutzen wir im Seminar **useHooks** als feste Sammlung
- Website: https://usehooks.com, npm-Paket: `@uidotdev/usehooks`
- Kleine, einzeln importierbare Hooks, ohne eigene Laufzeit-Abhängigkeiten außer React
- Laut README kompatibel mit React 18 und neuer

```bash
npm i @uidotdev/usehooks
```

```typescript
import { useDebounce, useLocalStorage } from '@uidotdev/usehooks'
```

# 8.1 useHooks als Standard-Hook-Sammlung / Kategorien

## Überblick (ca. 50 Hooks)

- **Zustand und Werte:** `useToggle`, `useCounter`, `useList`, `useMap`, `useSet`, `useQueue`, `useObjectState`, `useDefault`, `usePrevious`
- **Persistenz:** `useLocalStorage`, `useSessionStorage`, `useHistoryState`
- **Zeit und Rate:** `useDebounce`, `useThrottle`, `useIdle`
- **Browser und Umgebung:** `useMediaQuery`, `useWindowSize`, `useWindowScroll`, `useNetworkState`, `useOrientation`, `useBattery`, `useGeolocation`, `usePreferredLanguage`
- **Interaktion:** `useClickAway`, `useHover`, `useLongPress`, `useMouse`, `useCopyToClipboard`, `useLockBodyScroll`
- **Elemente und Lebenszyklus:** `useIntersectionObserver`, `useMeasure`, `useIsClient`, `useIsFirstRender`, `useDocumentTitle`
- Einige Hooks (z. B. `useInterval`, `useTimeout`, `useEventListener`, `useKeyPress`, `useFetch`) sind als experimentell markiert und nur in der Experimental-Version verfügbar

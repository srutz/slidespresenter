# 2.2 React Einführung / "Hello World" in React

- Die kanonische "Hello World"-Anwendung in React sieht so aus:

```typescript
import React, { useState } from 'react';

export function Counter() {
    const [count, setCount] = useState(0)
    return (
        <div>
            <button onClick={() => setCount(count + 1)}>Count : {count}</button>
        </div>
    )
}
```

- Die Funktion `useState` ist ein Hook, der es ermöglicht, Zustände in Funktionskomponenten zu verwenden.
- Alle Funktionen die mit `use` beginnen, sind sogenannte Hooks.
- useState() gibt ein Array zurück, das zwei Elemente enthält: den aktuellen Zustand und eine Funktion, um den Zustand zu aktualisieren.

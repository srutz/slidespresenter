
# 3.3 Komponenten, Props und State / Ausgabe von dynamischen Inhalten

## Ausgabe von dynamischen Inhalten

- In React können dynamische Inhalte in JSX mit geschweiften Klammern `{}` ausgegeben werden.
- In den geschweiften Klammern können JavaScript-Ausdrücke verwendet werden.
- JavaScript-Statements (for, if, switch, while,...) können nicht in JSX verwendet werden.
- JavaScript-Ausdrücke können Variablen, Funktionen, Operatoren und andere JavaScript-Elemente enthalten.

```typescript
// Komponente.tsx

const Komponente = () => {
  const text = "Ich bin ein Text";
  return <div>{text}</div>;
}
```

# 3.3 Komponenten, Props und State / Ausgabe von dynamischen Inhalten

## Ausgabe von dynamischen Inhalten (Props)

- Komponenten können mit Props konfiguriert werden.
- Props sind Eigenschaften, die von Elternkomponenten an Kindkomponenten übergeben werden.
- Props können in der Komponente verwendet werden, um dynamische Inhalte auszugeben.

```typescript
// Komponente.tsx

interface KomponenteProps {
  text: string;
}

const Komponente = (props: KomponenteProps) => {
  return <div>{props.text}</div>;
}
```

# 3.3 Komponenten, Props und State / Ausgabe von dynamischen Inhalten

## JSX als Ausdruck

- JSX kann als Ausdruck verwendet werden.
- JSX-Ausdrücke können in Variablen gespeichert und in anderen JSX-Elementen verwendet werden.

```typescript
// Komponente.tsx

const Komponente = () => {
  const text = "Ich bin ein Text";
  const element = <div>{text}</div>;
  return element;
}
```


# 7.9 Hooks und moderne React Patterns / Verwenden von "useCallback()"

## useCallback

- `useCallback` gibt eine **memoizierte Funktion** zurück — dieselbe Funktionsreferenz wird zwischen Renders wiederverwendet, solange sich die Abhängigkeiten nicht ändern.
- Ohne `useCallback` wird bei jedem Render eine neue Funktion erzeugt. Das ist normalerweise kein Problem — es wird aber zum Problem, wenn:
  - die Funktion als Prop an eine mit `React.memo` optimierte Kindkomponente übergeben wird
  - die Funktion in der Abhängigkeitsliste eines anderen Hooks (`useEffect`, `useMemo`) steht

```typescript
import { useCallback, useState } from 'react'

export function Counter() {
    const [count, setCount] = useState(0)

    const increment = useCallback(() => {
        setCount(c => c + 1)
    }, [])

    return (
        <div>
            <p>{count}</p>
            <button onClick={increment}>+1</button>
        </div>
    )
}
```

## useCallback mit React.memo

- Das klassische Szenario: eine Kindkomponente erhält eine Callback-Funktion als Prop.
- Ohne `useCallback` bekommt das Kind bei jedem Render eine *neue* Funktion → `React.memo` kann nicht greifen.

```typescript
import { memo, useCallback, useState } from 'react'

const SaveButton = memo(({ onSave }: { onSave: () => void }) => {
    console.log('SaveButton gerendert')
    return <button onClick={onSave}>Speichern</button>
})

export function Form() {
    const [name, setName] = useState('')

    const handleSave = useCallback(() => {
        console.log('Gespeichert:', name)
    }, [name])

    return (
        <div>
            <input value={name} onChange={e => setName(e.target.value)} />
            <SaveButton onSave={handleSave} />
        </div>
    )
}
```

## useCallback — Wann einsetzen?

- `useCallback` ist eine **reine Optimierung** — es lohnt sich nur in bestimmten Situationen:

| Situation | useCallback sinnvoll? |
|-----------|----------------------|
| Callback an `React.memo`-Kind | ✅ Ja |
| Callback in `useEffect`-Deps | ✅ Ja |
| Einfacher Event-Handler im JSX | ❌ Nein |
| Funktion nur lokal verwendet | ❌ Nein |

- Der **React Compiler** (React 19+) macht `useCallback` in vielen Fällen überflüssig — er memoiziert automatisch.
- Falsch eingesetzt erhöht `useCallback` nur die Komplexität ohne Gewinn.

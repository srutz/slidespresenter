# 17.2 Legacy- und Überblicksthemen / Create React App und contextType

## Create React App (CRA)

- Das React-Team hat CRA im Februar 2025 offiziell eingestellt (deprecated); es gibt keine neuen Features und keine Unterstützung für neue React-Versionen mehr.
- Abhängigkeiten (Webpack, Jest-Setup) veralten, Dev-Server und Build sind langsam.
- Empfohlene Wege: neues Projekt mit Vite oder ein Framework (z. B. Next.js, React Router als Framework).
- Migration zu Vite, grob:
    1. `react-scripts` entfernen, `vite` und `@vitejs/plugin-react` installieren.
    2. `public/index.html` nach `index.html` im Projektstamm verschieben, `<script type="module" src="/src/main.tsx">` ergänzen.
    3. Umgebungsvariablen von `REACT_APP_` auf `VITE_` umstellen, Zugriff über `import.meta.env`.
    4. Skripte `dev`, `build`, `preview` in `package.json` anlegen.
    5. Tests von Jest auf Vitest umstellen.

# 17.2 Legacy- und Überblicksthemen / contextType in Klassenkomponenten

- `static contextType` bindet eine Klassenkomponente an genau einen Context; Zugriff über `this.context`.
- Moderne Alternative: `useContext` in Funktionskomponenten, beliebig viele Contexts.

```typescript
// Legacy
class ThemeLabel extends React.Component {
    static contextType = ThemeContext
    render() {
        return <span>{this.context}</span>
    }
}

// Modern
function ThemeLabel() {
    const theme = useContext(ThemeContext)
    return <span>{theme}</span>
}
```

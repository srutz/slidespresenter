

# 3.2 Komponenten, Props und State / Arbeiten mit mehreren React-Komponenten

## Exports und Default-Exports

- In React können Komponenten auf verschiedene Arten exportiert werden. Die beiden Methoden sind `export` und `export default`.

```typescript
// Komponente.tsx

export const Komponente = () => {
  return <div>Ich bin eine Komponente</div>;
}
```

In diesem Beispiel wird die Komponente `Komponente` exportiert. Um die Komponente in einer anderen Datei zu verwenden, muss sie importiert werden.

```typescript
// App.tsx
import { Komponente } from './Komponente';

const App = () => {
  return (
    <div>
      <Komponente />
    </div>
  );
}
```

## Default-Export

- Eine weitere Möglichkeit, Komponenten zu exportieren, ist der Default-Export. Hierbei wird die Komponente direkt exportiert, ohne dass sie einen Namen hat.

```typescript
// Komponente.tsx

const Komponente = () => {
  return <div>Ich bin eine Komponente</div>;
}

export default Komponente;
```

In diesem Beispiel wird die Komponente `Komponente` als Default-Export exportiert. Um die Komponente in einer anderen Datei zu verwenden, muss sie importiert werden.

```typescript
// App.tsx
import Komponente from './Komponente';

const App = () => {
  return (
    <div>
      <Komponente />
    </div>
  );
}
```

- Der Default-Export kann auch mit benannten Exports kombiniert werden.

```typescript
// Komponente.tsx

const Komponente = () => {
  return <div>Ich bin eine Komponente</div>;
}

export const Zusatz = () => {
  return <div>Ich bin ein Zusatz</div>;
}

export default Komponente;
```

# 3.2 Komponenten, Props und State / Arbeiten mit mehreren React-Komponenten

## Schreiben von Komponenten als Funktionen oder als Arrow Functions

- Komponenten können als Funktionen oder als Arrow Functions geschrieben werden. Beide Varianten sind gültig und haben ihre Vor- und Nachteile.

```typescript
// Komponente.tsx

function Komponente() {
  return <div>Ich bin eine Komponente</div>;
}
```

```typescript
// Komponente.tsx

const Komponente = () => {
  return <div>Ich bin eine Komponente</div>;
}
```

## Schreiben von Komponenten als Funktionen oder als Arrow Functions

- Die Verwendung von Arrow Functions hat den Vorteil, dass der `this`-Kontext nicht verändert wird.
- Dieser Vorteil ist jedoch in React kaum relevant, da der `this`-Kontext in Funktionskomponenten nicht verwendet wird.

# 4.4 Styling mit Tailwind CSS / Responsive Design und Breakpoints

## Mobile-first und Breakpoint-Präfixe

- Klassen ohne Präfix gelten für alle Bildschirmgrößen, also zuerst das Layout für Smartphones schreiben
- Präfixe gelten "ab" einer Mindestbreite (`min-width`) und überschreiben die kleineren Werte

| Präfix | Ab Breite | Typisches Gerät |
|--------|-----------|-----------------|
| `sm:`  | 640px     | großes Smartphone |
| `md:`  | 768px     | Tablet |
| `lg:`  | 1024px    | Laptop |
| `xl:`  | 1280px    | Desktop |
| `2xl:` | 1536px    | großer Desktop |

- Häufiger Fehler: `sm:` bedeutet nicht "auf Smartphones", sondern "ab 640px"

# 4.4 Styling mit Tailwind CSS / Responsive Design und Breakpoints

## Beispiel: Anpassendes Karten-Grid

```typescript
export function ProductGrid({ children }: { children: React.ReactNode }) {
  return (
    <div className="grid grid-cols-1 gap-4 p-4 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4">
      {children}
    </div>
  )
}
```

- Smartphone: eine Spalte, ab 640px zwei, ab 1024px drei, ab 1280px vier Spalten
- Auch andere Eigenschaften lassen sich anpassen: `text-base md:text-lg`, `p-4 lg:p-8`
- Elemente ein- und ausblenden: `hidden md:block` (nur ab Tablet) oder `md:hidden` (nur mobil)

## Max-Varianten und Container Queries

- Mit `max-md:` gilt eine Klasse nur unterhalb des Breakpoints: `max-md:flex-col`
- Bereiche: `md:max-xl:grid-cols-2` gilt nur zwischen `md` und `xl`
- Tailwind 4 enthält Container Queries ohne Plugin: das Elternelement bekommt `@container`, die Kinder reagieren auf dessen Breite

```typescript
<div className="@container">
  <div className="flex flex-col gap-2 @md:flex-row @md:items-center">
    <img className="size-16 rounded-full" src={avatar} alt="" />
    <p>Reagiert auf die Breite des Containers, nicht des Fensters</p>
  </div>
</div>
```

- Eigene Breakpoints werden in `@theme` definiert, z.B. `--breakpoint-3xl: 120rem;` (siehe 4.9)


# 3.5 Komponenten, Props und State / React-Komponenten und Ereignisverarbeitung

## Ereignisverarbeitung

- In React können Ereignisse in JSX mit vordefinierten Attributen verarbeitet werden.
  - onClick
  - onChange
  - onSubmit
  - onMouseOver
  - onMouseOut
  - onFocus
  - onBlur
  - onKeyPress
  - onKeyDown
  - onKeyUp
- Ereignisse können mit Inline-Funktionen oder Funktionen außerhalb des JSX-Elements verarbeitet werden.


# 3.5 Komponenten, Props und State / React-Komponenten und Ereignisverarbeitung

## Ereignisverarbeitung

Beispiel für die Verarbeitung von Ereignissen in React:

```typescript
export function EreignisKomponente() {
  const handleClick = () => {
    alert("Button wurde geklickt")
  }
  return (
    <div>
      <button onClick={handleClick}>Klick mich</button>
    </div>
  )
}
```

## Ereignisverarbeitung Inline

Ereignisse können auch inline in JSX verarbeitet werden:

```typescript
export function EreignisKomponente() {
  return (
    <div>
      <button onClick={() => alert("Button wurde geklickt")}>Klick mich</button>
    </div>
  )
}
```

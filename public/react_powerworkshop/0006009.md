# 6.9 React mit TypeScript / Typische TypeScript-Patterns in React

## Props von HTML-Elementen erweitern

```typescript
import type { ComponentProps, PropsWithChildren } from 'react';

type ButtonProps = ComponentProps<'button'> & {
    variant?: 'primary' | 'secondary'
}

function Button({ variant = 'primary', className, ...rest }: ButtonProps) {
    return <button className={`btn-${variant} ${className ?? ''}`} {...rest} />
}

function Panel({ children }: PropsWithChildren<{ title: string }>) {
    return <section>{children}</section>
}
```

- ComponentProps<'button'> übernimmt alle nativen Attribute und Events (onClick, disabled, ...).
- In React 19 ist ref bei Funktionskomponenten eine normale Prop und in ComponentProps enthalten.

## Generische Komponenten

```typescript
type ListProps<T> = {
    items: T[]
    renderItem: (item: T) => React.ReactNode
    getKey: (item: T) => string | number
}

function List<T>({ items, renderItem, getKey }: ListProps<T>) {
    return <ul>{items.map(item => <li key={getKey(item)}>{renderItem(item)}</li>)}</ul>
}

<List items={users} getKey={u => u.id} renderItem={u => u.name} />
```

- T wird aus items abgeleitet, u ist im Callback vollständig typisiert.

## Utility Types

```typescript
type User = { id: number; name: string; email: string; role: Role }

type UserDraft = Partial<User>                       // alle Felder optional
type UserPreview = Pick<User, 'id' | 'name'>         // nur ausgewählte Felder
type NewUser = Omit<User, 'id'>                      // ohne id
type RoleLabels = Record<Role, string>               // je Role ein Eintrag, vollständig

const labels: RoleLabels = {
    admin: 'Administrator',
    editor: 'Redakteur',
    viewer: 'Leser',
}
```

- Polymorphe Komponenten (Prop `as`) lassen sich mit Generics typisieren, werden aber schnell komplex. Meist reichen Varianten-Props oder composition.

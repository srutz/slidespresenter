
# 13.6 Testing / Komponenten-Tests

## Erstellen eines Tests mit Jest-Dom

Hier wird in einem Test die Komponente `Banner` getestet. Die Komponente wird gerendert und dann wird geprüft, ob der Text "Hello Banner" im DOM vorhanden ist.

```typescript
import '@testing-library/jest-dom'
import { render, screen, waitFor} from '@testing-library/react';
import { Banner } from '../004_banner/Banner'
test("reacttest", async () => {
    render(<Banner visible text="Hello Banner"></Banner>)
    await waitFor(() => {
        const matcher = expect(screen.getByText("Hello Banner"))
        matcher.toBeInTheDocument()
    })
})
```

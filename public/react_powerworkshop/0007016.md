# 7.16 Hooks und moderne React Patterns / useDeferredValue()

## useDeferredValue

- `useDeferredValue(value)` liefert zunächst den **alten** Wert zurück und aktualisiert ihn danach in einem Hintergrund-Render mit niedriger Priorität
- Die dringende Aktualisierung (Eingabefeld) wird sofort gerendert, der teure Teil (Liste) folgt
- Der Hintergrund-Render ist unterbrechbar: tippt der Benutzer weiter, wird er verworfen
- Man hat kein eigenes `setState` unter Kontrolle, z. B. weil der Wert als Prop von außen kommt
- Der teure Teil sollte mit `memo()` eingewickelt sein, sonst rendert er auch bei unverändertem Wert neu

# 7.16 Hooks und moderne React Patterns / useDeferredValue() Beispiel mit großer Liste

```typescript
import { memo, useDeferredValue, useState } from 'react'

const items = Array.from({ length: 20000 }, (_, i) => `Eintrag ${i}`)

const FilteredList = memo(function FilteredList({ query }: { query: string }) {
    const filtered = items.filter(item => item.includes(query))
    return <ul>{filtered.map(item => <li key={item}>{item}</li>)}</ul>
})

export function Search() {
    const [query, setQuery] = useState('')
    const deferredQuery = useDeferredValue(query)
    const isStale = query !== deferredQuery

    return (
        <div>
            <input value={query} onChange={e => setQuery(e.target.value)} />
            <div style={{ opacity: isStale ? 0.5 : 1 }}>
                <FilteredList query={deferredQuery} />
            </div>
        </div>
    )
}
```

- `query !== deferredQuery` zeigt an, dass der Hintergrund-Render noch läuft

# 7.16 Hooks und moderne React Patterns / useDeferredValue() im Vergleich

| | useDeferredValue | useTransition | Debouncing |
|---|---|---|---|
| Ansatz | Wert verzögern | State-Update als nicht dringend markieren | Update zeitlich verzögern |
| Typischer Einsatz | Wert kommt als Prop / Hook | Man ruft `setState` selbst auf | Netzwerk-Requests |
| Unterbrechbar | Ja | Ja | Nein, nur Timer |
| Feste Wartezeit | Nein | Nein | Ja (z. B. 300 ms) |
| Reduziert Requests | Nein | Nein | Ja |

- `useDeferredValue` und `useTransition` helfen bei **teurem Rendern**, nicht bei teuren Requests
- Für Server-Requests zusätzlich Debouncing einsetzen (siehe Kapitel 8: useDebounce)
- `useDeferredValue(value, initialValue)` (React 19): `initialValue` wird beim ersten Render verwendet, danach folgt der echte Wert im Hintergrund

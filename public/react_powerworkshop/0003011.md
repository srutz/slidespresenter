
# 3.11 Komponenten, Props und State / Arbeiten mit Listen und Bedingungen

- Listen und Bedingungen sind in React sehr wichtig, um dynamische Inhalte auszugeben.
- Listen und Bedingungen können in JSX mit JavaScript-Ausdrücken verwendet werden.
- Alternativ kann man auch JSX in Variablen speichern und in JSX verwenden.
- JSX ist schließlich nur eine Erweiterung von JavaScript und kann in JavaScript-Ausdrücken verwendet werden.

# 3.11 Komponenten, Props und State / Arbeiten mit Listen und Bedingungen

## Listen

- Listen können in JSX mit `map()` ausgegeben werden.

```typescript
export function List() {
    const items = ['Item 1', 'Item 2', 'Item 3'];
    return (
        <ul>
            {items.map((item, index) => <li key={index}>{item}</li>)}
        </ul>
    );
}
```

## Bedingungen

- Bedingungen können in JSX mit dem ternären Operator `?` ausgegeben werden.

```typescript
export function Conditional() {
    const condition = true;
    return (
        <div>
            {condition ? <p>Bedingung ist wahr</p> : <p>Bedingung ist falsch</p>}
        </div>
    );
}
```

## Einfache Bedingungen mit `&&`

- Einfache Bedingungen können in JSX mit `&&` ausgegeben werden.
- Dies funktioniert weil undefined, null und false in JSX nicht gerendert werden.

```typescript
export function Conditional() {
    const condition = true;
    return (
        <div>
            {condition && <p>Bedingung ist wahr</p>}
        </div>
    );
}
```

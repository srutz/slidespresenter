
# 11.5 Formulare und Validierung / Validierungs-Feedback hinzufügen

## Validierungs-Feedback hinzufügen

- Nachdem wir die benutzerdefinierte Validierung hinzugefügt haben, können wir auch Validierungs-Feedback hinzufügen.
- Dazu kann zum Beispiel ein State namens "error" im vorherigen Beispiel verwendet werden.
- Wenn der Wert des Eingabefeldes ungültig ist, wird eine Fehlermeldung gerendert.

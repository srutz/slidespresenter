
# 22.12 SemVer und npm (Zusatzthema) / npm install vs. npm ci

## npm install

```bash
npm install
npm install <paket>
npm install <paket>@<version>
npm install -D <paket>     # als devDependency
```

- Installiert Abhängigkeiten gemäß `package.json`.
- Aktualisiert dabei bei Bedarf auch `package-lock.json` (z. B. wenn eine neue Range erstmals aufgelöst wird oder Pakete fehlen).
- Kann also, in Grenzen, von der bestehenden Lock-Datei abweichen.

# 22.12 SemVer und npm (Zusatzthema) / npm install vs. npm ci

## npm ci ("clean install")

```bash
npm ci
```

- Installiert **exakt** das, was in `package-lock.json` steht - `package.json` und Lock-Datei müssen konsistent sein, sonst bricht der Befehl ab.
- Löscht vorher den vorhandenen `node_modules`-Ordner komplett.
- Aktualisiert die Lock-Datei **nie**.
- Deutlich schneller und reproduzierbar - der Standard-Befehl für CI/CD-Pipelines und Docker-Builds.

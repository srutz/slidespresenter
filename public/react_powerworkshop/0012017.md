
# 12.17 State Management mit Zustand / Alternativen zu Redux – Zustand und Immer

## Zustand

- `zustand` ist eine schlanke State-Management-Bibliothek, die ohne Provider und Boilerplate auskommt.
- Der Store wird als einfacher Hook definiert – kein Slice, kein Reducer, kein Dispatch.
- Zustand eignet sich besonders für mittlere Anwendungen, bei denen Redux zu viel Overhead wäre.

```typescript
import { create } from 'zustand'

interface CounterStore {
    count: number
    increment: () => void
    decrement: () => void
}

const useCounterStore = create<CounterStore>((set) => ({
    count: 0,
    increment: () => set((state) => ({ count: state.count + 1 })),
    decrement: () => set((state) => ({ count: state.count - 1 })),
}))

export function Counter() {
    const { count, increment, decrement } = useCounterStore()
    return (
        <div>
            <button onClick={decrement}>-</button>
            <span>{count}</span>
            <button onClick={increment}>+</button>
        </div>
    )
}
```

# 12.17 State Management mit Zustand / Alternativen zu Redux – Zustand und Immer

## Immer

- `immer` ermöglicht es, State-Mutationen direkt zu schreiben, ohne manuell Kopien zu erstellen.
- Unter der Haube erzeugt Immer unveränderliche Kopien – das alias-Problem entfällt.
- Immer wird häufig zusammen mit Zustand verwendet (`zustand/middleware/immer`), ist aber auch solo oder mit Redux einsetzbar.

```typescript
import { create } from 'zustand'
import { immer } from 'zustand/middleware/immer'

interface TodoStore {
    todos: { id: number; text: string; done: boolean }[]
    toggle: (id: number) => void
}

const useTodoStore = create<TodoStore>()(
    immer((set) => ({
        todos: [{ id: 1, text: 'Lernen', done: false }],
        toggle: (id) =>
            set((state) => {
                const todo = state.todos.find((t) => t.id === id)
                if (todo) todo.done = !todo.done  // direkte Mutation – Immer macht's sicher
            }),
    }))
)
```

- Ohne Immer müsste `toggle` eine neue Array-Kopie mit `map` erstellen – mit Immer entfällt das.


# 12.6 State Management mit Zustand / Zustand mit Immer

## Warum Immer?

- Immer erlaubt es, State **scheinbar direkt zu mutieren** – intern erstellt es dabei ein neues, immutables Objekt.
- Dadurch entfällt das manuelle Spreaden bei tief verschachteltem State.
- Zustand hat eine eigene Immer-Middleware: `immer` aus `zustand/middleware/immer`.

Installation (falls noch nicht vorhanden):

```bash
npm install immer
```

## Todo-Store mit Immer-Middleware

```typescript
import { create } from 'zustand'
import { immer } from 'zustand/middleware/immer'

type Todo = { id: number; text: string; done: boolean }

type TodoStore = {
    todos: Todo[]
    addTodo: (text: string) => void
    toggleTodo: (id: number) => void
    removeTodo: (id: number) => void
}

let nextId = 1

export const useTodoStore = create<TodoStore>()(
    immer((set) => ({
        todos: [],
        addTodo: (text) =>
            set((state) => {
                state.todos.push({ id: nextId++, text, done: false })
            }),
        toggleTodo: (id) =>
            set((state) => {
                const todo = state.todos.find((t) => t.id === id)
                if (todo) todo.done = !todo.done
            }),
        removeTodo: (id) =>
            set((state) => {
                state.todos = state.todos.filter((t) => t.id !== id)
            }),
    }))
)
```

- `immer(...)` wrapping macht den `set`-Callback zu einem Immer-Draft.
- State kann **direkt mutiert** werden – Immer erzeugt hinter den Kulissen ein neues Objekt.
- `create<TodoStore>()()` – doppelte Klammern sind bei TypeScript + Middleware nötig (Currying für bessere Typinferenz).

# 12.6 State Management mit Zustand / Zustand mit Immer – Tief verschachtelter State

## Beispiel: Verschachtelte Konfiguration

Ohne Immer – unübersichtlich:

```typescript
set((state) => ({
    config: {
        ...state.config,
        ui: {
            ...state.config.ui,
            theme: {
                ...state.config.ui.theme,
                primaryColor: '#ff0000',
            },
        },
    },
}))
```

Mit Immer – direkt und lesbar:

```typescript
set((state) => {
    state.config.ui.theme.primaryColor = '#ff0000'
})
```

- Der Vorteil von Immer wächst mit der Tiefe der Verschachtelung.
- Immer ist bei flachen Stores nicht nötig – aber sobald Objekte mehrere Ebenen tief sind, lohnt es sich.

# 14.7 Build, Deployment und Produktion / Deployment auf Cloud- und Hosting-Plattformen

## Überblick

- Eine gebaute SPA ist statisch: jeder Hoster für statische Dateien genügt.
- Konfiguration: Build-Befehl `npm run build`, Ausgabeverzeichnis `dist`.

| Plattform | Eigenschaften |
|---|---|
| Netlify | Git-Integration, Preview-Deployments, Rewrites per `_redirects` oder `netlify.toml`, Functions |
| Vercel | Git-Integration, Preview pro Pull Request, Rewrites in `vercel.json`, Serverless Functions |
| Cloudflare Pages | Globales CDN, Git-Integration, SPA-Fallback automatisch ohne 404-Seite, Workers für API |
| GitHub Pages | Kostenlos, einfach, Unterpfad `/repo/` (siehe `base`), SPA-Fallback nur per 404.html-Trick |
| S3 + CloudFront | Volle Kontrolle in AWS, Fehlerseiten 403/404 auf `/index.html` mit Status 200 umleiten |

# 14.7 Build, Deployment und Produktion / SPA-Fallback konfigurieren

- Netlify, `public/_redirects`:

```bash
/*    /index.html   200
```

- Vercel, `vercel.json`:

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

- Cloudflare Pages: ohne eigene `404.html` wird automatisch als SPA behandelt.
- S3 + CloudFront: Custom Error Responses für 403 und 404 mit Antwortseite `/index.html` und Status 200.
- Der Fallback ersetzt nicht die Regel für `/api`: API-Aufrufe über Rewrite/Proxy zum Backend weiterleiten.

# 14.7 Build, Deployment und Produktion / Auswahlkriterien

- Preview-Deployments: für jeden Pull Request eine eigene URL zum Review durch Team und Fachbereich.
- Backend: Wo läuft die API? Proxy/Rewrites für `/api`, um CORS zu vermeiden.
- Kosten und Limits: Bandbreite, Build-Minuten, Teamgröße.
- Datenschutz und Standort: Region, Auftragsverarbeitung (DSGVO), EU-Hosting.
- Kontrolle: Managed Plattform (schnell eingerichtet) gegen eigene Infrastruktur mit Docker/Kubernetes (volle Kontrolle, mehr Aufwand).
- Unabhängigkeit: Mit dem Docker-Image bleibt man beim Hoster flexibel.
- Rollback: Alle genannten Plattformen halten frühere Deployments vor und können sofort zurückschalten.


# 11.14 Formulare und Validierung / Form-Libraries

## Warum eine Form-Library?

- Formulare mit vielen Feldern, Abhängigkeiten und Validierungen werden schnell komplex.
- Handgeschriebener State für jedes Feld, jeden Fehler und jeden Touch-Status ist mühsam und fehleranfällig.
- Form-Libraries übernehmen: **State-Verwaltung**, **Validierung**, **Touched/Dirty-Tracking** und **Submit-Handling**.

| Library | Besonderheit |
|---|---|
| **TanStack Form** | Headless, TypeScript-first, framework-agnostisch |
| **React Hook Form** | Sehr weit verbreitet, minimale Re-renders |
| **Formik** | Klassiker, einfacher Einstieg |
| **Zod + RHF** | Kombination: Schema-Validierung + RHF |

## TanStack Form — Grundkonzept

- TanStack Form ist **headless**: es liefert keine fertige UI, sondern nur Logik via Hooks.
- Zentrales Objekt ist `form` — erstellt mit `useForm()`. Es enthält alle Felder, Validierungen und den Submit-Handler.
- Felder werden mit `form.Field` deklariert und bekommen `field`-Props (value, onChange, onBlur, errors).

```bash
npm install @tanstack/react-form
```

```typescript
import { useForm } from '@tanstack/react-form'

export function LoginForm() {
    const form = useForm({
        defaultValues: { email: '', password: '' },
        onSubmit: async ({ value }) => {
            console.log('Submit:', value)
        },
    })

    return (
        <form onSubmit={(e) => { e.preventDefault(); form.handleSubmit() }}>
            <form.Field name="email">
                {(field) => (
                    <div>
                        <label>E-Mail</label>
                        <input
                            value={field.state.value}
                            onChange={(e) => field.handleChange(e.target.value)}
                            onBlur={field.handleBlur}
                        />
                    </div>
                )}
            </form.Field>
            <button type="submit">Anmelden</button>
        </form>
    )
}
```

## TanStack Form — Validierung

- Validierung kann **synchron** (sofort) oder **asynchron** (z. B. Server-Check) sein.
- Validierungs-Trigger: `onChange`, `onBlur`, `onSubmit` — frei kombinierbar.
- Fehlermeldungen landen in `field.state.meta.errors` und können direkt im JSX gerendert werden.

```typescript
<form.Field
    name="email"
    validators={{
        onBlur: ({ value }) => {
            if (!value.includes('@')) return 'Keine gültige E-Mail-Adresse'
            return undefined
        },
        onChangeAsync: async ({ value }) => {
            const taken = await checkEmailTaken(value)
            return taken ? 'E-Mail bereits vergeben' : undefined
        },
    }}
>
    {(field) => (
        <div>
            <label>E-Mail</label>
            <input
                value={field.state.value}
                onChange={(e) => field.handleChange(e.target.value)}
                onBlur={field.handleBlur}
            />
            {field.state.meta.errors.map((err, i) => (
                <span key={i} style={{ color: 'red' }}>{err}</span>
            ))}
        </div>
    )}
</form.Field>
```

## TanStack Form — Schema-Validierung mit Zod

- TanStack Form lässt sich mit **Zod** (oder Valibot / ArkType) koppeln — über einen Adapter.
- Das Zod-Schema beschreibt die gesamte Form-Struktur und wird einmalig übergeben.
- Vorteil: dasselbe Schema kann auch server-seitig (z. B. in tRPC / Hono) wiederverwendet werden.

```bash
npm install zod @tanstack/zod-form-adapter
```

```typescript
import { useForm } from '@tanstack/react-form'
import { zodValidator } from '@tanstack/zod-form-adapter'
import { z } from 'zod'

const schema = z.object({
    email: z.string().email('Keine gültige E-Mail'),
    password: z.string().min(8, 'Mindestens 8 Zeichen'),
})

export function LoginForm() {
    const form = useForm({
        defaultValues: { email: '', password: '' },
        validatorAdapter: zodValidator(),
        validators: { onSubmit: schema },
        onSubmit: async ({ value }) => console.log(value),
    })

    return (
        <form onSubmit={(e) => { e.preventDefault(); form.handleSubmit() }}>
            <form.Field name="email">
                {(field) => (
                    <>
                        <input
                            value={field.state.value}
                            onChange={(e) => field.handleChange(e.target.value)}
                            onBlur={field.handleBlur}
                        />
                        {field.state.meta.errors[0] && (
                            <span style={{ color: 'red' }}>{field.state.meta.errors[0]}</span>
                        )}
                    </>
                )}
            </form.Field>
            <button type="submit">Anmelden</button>
        </form>
    )
}
```

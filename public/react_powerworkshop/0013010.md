
# 13.10 Testing / E2E-Tests

- E2E-Tests (End-to-End-Tests) testen die Anwendung von der Benutzeroberfläche bis zur Datenbank.
- E2E-Tests simulieren die Interaktion eines Benutzers mit der Anwendung.
- E2E-Tests können mit verschiedenen Tools durchgeführt werden.
- Beispiele: Cypress, Selenium, Puppeteer

```typescript
// Beispiel für E2E-Tests mit Cypress
describe('My First Test', () => {
  it('Visits the Kitchen Sink', () => {
    cy.visit('https://example.cypress.io');
    cy.contains('type').click();
    cy.url().should('include', '/commands/actions');
    cy.get('.action-email')
      .type('test@example.com')
      .should('have.value', 'test@example.com');
    cy.get('.action-disabled')
      .should('be.disabled');
  });
});
```

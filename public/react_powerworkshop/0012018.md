
# 12.18 State Management mit Zustand / Alternativen zu Redux – Jotai

## Jotai

- `jotai` folgt einem atomaren Ansatz: State wird in kleinen, unabhängigen Einheiten ("Atoms") verwaltet.
- Nur die Komponenten, die ein Atom verwenden, werden neu gerendert – sehr granulare Reaktivität.
- Kein Provider-Baum nötig (optional möglich), kein Boilerplate, TypeScript-freundlich.

```typescript
import { atom, useAtom } from 'jotai'

const countAtom = atom(0)

export function Counter() {
    const [count, setCount] = useAtom(countAtom)
    return (
        <div>
            <button onClick={() => setCount((c) => c - 1)}>-</button>
            <span>{count}</span>
            <button onClick={() => setCount((c) => c + 1)}>+</button>
        </div>
    )
}
```

## Abgeleitete Atoms

- Atoms können aus anderen Atoms abgeleitet werden – ähnlich wie berechnete Werte.

```typescript
import { atom, useAtom } from 'jotai'

const firstNameAtom = atom('Ada')
const lastNameAtom = atom('Lovelace')

const fullNameAtom = atom((get) => `${get(firstNameAtom)} ${get(lastNameAtom)}`)

export function FullName() {
    const [fullName] = useAtom(fullNameAtom)
    return <div>{fullName}</div>
}
```

## Vergleich der Alternativen

| | Redux Toolkit | Zustand | Jotai |
|---|---|---|---|
| Boilerplate | mittel | minimal | minimal |
| DevTools | sehr gut | gut | gut |
| Ansatz | Slice/Reducer | Store als Hook | Atoms |
| Eignet sich für | große Teams, komplexe Apps | mittlere Apps | fein-granulären State |


# 7.17 Hooks und moderne React Patterns / React 19: use() API

- use() ist eine neue API von React19 und kein Hook.
- In RSC (React Server Components) wird use() verwendet um Daten zu laden und dann kann das Promise welches die Daten liefert an eine Client-Component als Prop übergeben werden.
- Das Promise sollte nicht resolved werden, sondern nur an die Client-Component übergeben werden.

- Der Inhalt dieses Promises muss per JSON.stringify serialisierbar sein. Die Einschränkungen von JSON.stringify und JSON.parse gelten und sind grob wie folgt bei folgenden Objekten:

    - Funktionen
    - undefined
    - Symbol
    - BigInt
    - RegExp
    - Map
    - Set
    - WeakMap
    - WeakSet
    - Date
    - Error

- Außerdem dürfen keine Zyklen in den Objekten sein und die referenzielle Integrität wird von der JSON Serialisierung ebenfalls nicht erhalten.

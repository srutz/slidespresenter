# 8.4 useHooks als Standard-Hook-Sammlung / useMediaQuery: responsive und Farbschema

## useMediaQuery

- `useMediaQuery(query)` gibt `true` zurück, solange die CSS-Media-Query zutrifft, und reagiert auf Änderungen
- Gut, wenn **Logik** (nicht nur Layout) vom Medium abhängt; für reines Layout besser Tailwind-Breakpoints (`md:`) und CSS

```typescript
import { useMediaQuery } from '@uidotdev/usehooks'

export function ThemeInfo() {
    const prefersDark = useMediaQuery('(prefers-color-scheme: dark)')
    const isMobile = useMediaQuery('only screen and (max-width: 768px)')

    return (
        <div>
            <p>System-Theme: {prefersDark ? 'dunkel' : 'hell'}</p>
            {isMobile ? <MobileNav /> : <DesktopNav />}
        </div>
    )
}
```

# 8.4 useHooks als Standard-Hook-Sammlung / useClickAway: Dropdown schließen

- `useClickAway(callback)` gibt ein `ref` zurück; Klicks außerhalb des Elements rufen den Callback auf

```typescript
import { useState } from 'react'
import { useClickAway } from '@uidotdev/usehooks'

export function Dropdown() {
    const [open, setOpen] = useState(false)
    const ref = useClickAway<HTMLDivElement>(() => setOpen(false))

    return (
        <div ref={ref}>
            <button onClick={() => setOpen(o => !o)}>Menü</button>
            {open && (
                <ul>
                    <li>Profil</li>
                    <li>Abmelden</li>
                </ul>
            )}
        </div>
    )
}
```

- Das Typargument `<HTMLDivElement>` setzt typisierte Ref-Rückgabe voraus; ohne mitgelieferte Typen ggf. `useRef`-Typ per Cast ergänzen
- Tastatur nicht vergessen: Escape zum Schließen und Fokus-Verhalten (Barrierefreiheit)

# 8.4 useHooks als Standard-Hook-Sammlung / useWindowSize und useNetworkState

```typescript
import { useWindowSize, useNetworkState } from '@uidotdev/usehooks'

export function BrowserState() {
    const { width, height } = useWindowSize()
    const network = useNetworkState()

    return (
        <div>
            <p>Fenster: {width} x {height}</p>
            <p>Online: {network.online ? 'ja' : 'nein'}</p>
            <p>Verbindung: {network.effectiveType}, RTT {network.rtt} ms</p>
            {!network.online && <p>Offline-Modus: Änderungen werden später gesendet</p>}
        </div>
    )
}
```

- `useNetworkState` liefert `online`, `downlink`, `downlinkMax`, `effectiveType`, `rtt`, `saveData`, `type`
- Die Network Information API ist nicht in allen Browsern verfügbar (Safari/Firefox): Felder außer `online` können `undefined` sein
- `useWindowSize` rendert bei jedem Resize neu; für reine Breakpoint-Entscheidungen ist `useMediaQuery` sparsamer
- Beide Hooks nutzen Browser-APIs: bei SSR zunächst keine Werte (siehe `useIsClient`)

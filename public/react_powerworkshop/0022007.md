
# 22.7 SemVer und npm (Zusatzthema) / Von der Theorie zur Praxis

## SemVer als Fundament von npm

- **npm** (Node Package Manager) verwaltet die Abhängigkeiten eines JavaScript/TypeScript-Projekts.
- Praktisch jedes Paket im npm-Registry (npmjs.com) folgt der SemVer-Konvention für seine Versionsnummer.
- Weil sich npm auf SemVer verlassen kann, muss man Abhängigkeiten nicht mehr manuell aktualisieren und testen - npm kann selbstständig entscheiden, welche Updates "sicher" sind.
- Auf den folgenden Folien geht es darum, wie npm SemVer konkret nutzt:
  - Wie Versionen im Projekt festgehalten werden (`package.json`, `package-lock.json`)
  - Wie man Abhängigkeiten aktualisiert, prüft und absichert (`npm update`, `npm outdated`, `npm audit`, `npm ls`, ...)
  - Wie man SemVer bei Bedarf gezielt aushebeln kann (`overrides`)

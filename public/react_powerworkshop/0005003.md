# 5.3 React-Komponenten im Detail / Composition statt Vererbung

## Composition statt Vererbung

- React setzt auf Composition: Komponenten werden ineinander geschachtelt, nicht voneinander abgeleitet.
- Gründe gegen Vererbung:
    - Funktionskomponenten sind Funktionen, keine Klassen.
    - Gemeinsames Verhalten lässt sich über Props, children und Hooks teilen.
    - Tiefe Vererbungshierarchien sind schwer zu verstehen und zu ändern.
- Faustregel des React-Teams: Es gibt (so gut wie) keinen Fall, in dem Komponenten-Vererbung nötig ist.

# 5.3 React-Komponenten im Detail / Composition statt Vererbung

## Containment mit children

- Komponenten, die ihren Inhalt vorab nicht kennen, reichen ihn über die Prop children durch.

```typescript
import type { ReactNode } from 'react';

function Card({ children }: { children: ReactNode }) {
    return <div className="rounded border p-4 shadow">{children}</div>
}

export function App() {
    return (
        <Card>
            <h2>Titel</h2>
            <p>Beliebiger Inhalt</p>
        </Card>
    )
}
```

# 5.3 React-Komponenten im Detail / Composition statt Vererbung

## Slots über Props

- Für mehrere "Löcher" im Layout werden Elemente als normale Props übergeben.

```typescript
import type { ReactNode } from 'react';

type LayoutProps = { header: ReactNode; sidebar: ReactNode; children: ReactNode }

function Layout({ header, sidebar, children }: LayoutProps) {
    return (
        <div>
            <header>{header}</header>
            <aside>{sidebar}</aside>
            <main>{children}</main>
        </div>
    )
}

<Layout header={<Logo />} sidebar={<Menu />}>
    <Content />
</Layout>
```

# 5.3 React-Komponenten im Detail / Composition statt Vererbung

## Specialization

- Eine spezielle Komponente ist eine generische Komponente, die mit festen Props konfiguriert wird.

```typescript
type DialogProps = { title: string; children?: React.ReactNode }

function Dialog({ title, children }: DialogProps) {
    return <section><h1>{title}</h1>{children}</section>
}

function ConfirmDialog() {
    return (
        <Dialog title="Wirklich löschen?">
            <button>Ja</button> <button>Nein</button>
        </Dialog>
    )
}
```

- Wiederverwendbare Logik (statt Darstellung) wird über Custom Hooks geteilt, siehe Kapitel 7.

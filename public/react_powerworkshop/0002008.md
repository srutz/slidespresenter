# 2.8 React Einführung / Einführung in JSX (JavaScript XML oder JavaScript Syntax Extension)

## Was ist JSX?

- JSX (JavaScript XML) ist eine Syntax-Erweiterung für JavaScript/TypeScript, mit der HTML-ähnliche Struktur direkt im Code geschrieben werden kann.
- JSX ist kein eigener Browser-Standard, sondern wird von Build-Tools (Babel, TypeScript, SWC, Vite) in normale JavaScript-Funktionsaufrufe übersetzt.
- Der Browser versteht kein JSX — es muss vor der Auslieferung kompiliert (transpiliert) werden.
- JSX macht Komponenten lesbarer, da UI-Struktur und Logik in derselben Datei kombiniert werden.

# 2.8 React Einführung / Einführung in JSX (JavaScript XML oder JavaScript Syntax Extension)

## JSX-Grundregeln

- Ein JSX-Ausdruck muss genau **ein** Root-Element zurückgeben.
- Alle Tags müssen geschlossen werden — auch "leere" HTML-Tags wie `<img />`, `<br />` oder `<input />`.
- Groß-/Kleinschreibung entscheidet die Bedeutung: kleine Anfangsbuchstaben (`div`, `span`) sind HTML-Elemente, große Anfangsbuchstaben (`MyComponent`) sind React-Komponenten.

```typescript
function Example() {
    return (
        <div>
            <h1>Titel</h1>
            <img src="logo.png" />
        </div>
    )
}
```

## JavaScript-Ausdrücke in JSX

- Mit geschweiften Klammern `{}` wechselt man innerhalb von JSX zurück nach JavaScript/TypeScript.
- Innerhalb von `{}` sind nur **Ausdrücke** erlaubt (die einen Wert liefern) — keine Statements wie `if`, `for` oder `switch`.

```typescript
const name = "Welt"
function Greeting() {
    return <h1>Hallo, {name}! Die Summe ist {1 + 2}.</h1>
}
```

- Erlaubt: Variablen, Funktionsaufrufe, ternärer Operator, `&&`-Ausdrücke, `.map()`
- Nicht erlaubt: `if`-Statements oder `for`-Schleifen direkt innerhalb von `{}`

## Attribute in JSX

- Attribute werden wie in HTML geschrieben, folgen aber der **camelCase**-Konvention.
- `class` heißt in JSX `className`, `for` heißt `htmlFor` (beides reservierte JavaScript-Schlüsselwörter).
- `style` erwartet ein JavaScript-Objekt, keinen String.

```typescript
function Box() {
    return (
        <div className="box" style={{ color: 'red', fontSize: 20 }}>
            <label htmlFor="email">E-Mail</label>
            <input id="email" disabled />
        </div>
    )
}
```

- Boolesche Attribute wie `disabled` können ohne Wert geschrieben werden (entspricht `disabled={true}`).

## Fragments

- Da JSX genau ein Root-Element benötigt, wird oft ein zusätzliches, unnötiges `<div>` verwendet, um mehrere Elemente zu gruppieren.
- **Fragments** erlauben das Gruppieren mehrerer Elemente, ohne ein zusätzliches DOM-Element zu erzeugen.

```typescript
import { Fragment } from 'react'

function List() {
    return (
        <>
            <li>Erster Eintrag</li>
            <li>Zweiter Eintrag</li>
        </>
    )
}
```

- `<>...</>` ist die Kurzform für `<Fragment>...</Fragment>`.

# 2.8 React Einführung / Einführung in JSX (JavaScript XML oder JavaScript Syntax Extension)

## JSX wird zu JavaScript kompiliert

- JSX ist syntaktischer Zucker: Der Compiler übersetzt JSX in Aufrufe der Funktion `jsx()` (früher `React.createElement()`).

```typescript
// JSX:
const element = <h1 className="title">Hallo</h1>

// wird kompiliert zu (vereinfacht):
const element = jsx('h1', { className: 'title', children: 'Hallo' })
```

- Deshalb muss `React` in modernen Projekten (neue JSX-Transform seit React 17) nicht mehr explizit importiert werden, nur um JSX zu verwenden.
- Diese Übersetzung erklärt auch, warum jeder JSX-Ausdruck einen Wert (ein React-Element) liefert.

## JSX und TypeScript

- Dateien mit JSX-Syntax und TypeScript verwenden die Endung `.tsx` (statt `.ts`).
- TypeScript prüft JSX wie normalen Code: Props werden typisiert, Tippfehler bei Attributen werden erkannt.
- Der Rückgabetyp einer Komponente ist meist implizit `ReactNode` bzw. `JSX.Element`.

```typescript
type GreetingProps = {
    name: string
}
function Greeting({ name }: GreetingProps) {
    return <h1>Hallo, {name}!</h1>
}
```

## Beispiel: Daten mit JSX ausgeben – TodoItem

- Daten aus Arrays/Objekten werden typischerweise über Props an Komponenten übergeben und dann mit `{}` in JSX ausgegeben.

```typescript
type Todo = {
    id: number
    todo: string
    completed: boolean
    userId: number
}

type TodoItemProps = {
    todo: Todo
}

export function TodoItem({ todo }: TodoItemProps) {
    return (
        <li>
            <input type="checkbox" checked={todo.completed} readOnly />
            <span>{todo.completed ? <s>{todo.todo}</s> : todo.todo}</span>
        </li>
    )
}
```

- `TodoItem` bekommt ein einzelnes `Todo`-Objekt als Prop und gibt dessen Felder mit `{}` in JSX aus.

## Beispiel: Daten mit JSX ausgeben – TodoList

- Eine Liste von Objekten wird mit `.map()` in JSX-Elemente umgewandelt. Jedes erzeugte Element benötigt ein eindeutiges `key`-Attribut.

```typescript
type TodoListProps = {
    todos: Todo[]
}

export function TodoList({ todos }: TodoListProps) {
    return (
        <ul>
            {todos.map(todo => <TodoItem key={todo.id} todo={todo} />)}
        </ul>
    )
}
```

- Verwendung mit Beispieldaten:

```typescript
const todos: Todo[] = [
    { id: 1, todo: "Do something nice for someone you care about", completed: false, userId: 152 },
    { id: 2, todo: "Memorize a poem", completed: true, userId: 13 },
    { id: 3, todo: "Watch a classic movie", completed: true, userId: 68 },
]

export function App() {
    return <TodoList todos={todos} />
}
```

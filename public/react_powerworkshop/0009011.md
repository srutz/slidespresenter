# 9.11 HTTP, APIs und Server State / TanStack Query: Mutations

## useMutation

- Queries lesen Daten, **Mutations** verändern sie (POST, PUT, PATCH, DELETE).
- Mutations laufen nicht automatisch, sondern werden explizit mit `mutate()` ausgelöst.

```typescript
import { useMutation } from '@tanstack/react-query'

type Todo = { id: number; todo: string; completed: boolean }
type NewTodo = { todo: string; completed: boolean; userId: number }

async function createTodo(newTodo: NewTodo): Promise<Todo> {
    const res = await fetch('https://dummyjson.com/todos/add', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(newTodo),
    })
    if (!res.ok) throw new Error(`HTTP ${res.status}`)
    return res.json()
}

const mutation = useMutation({
    mutationFn: createTodo,
})
```

## mutate, Status und Callbacks

```typescript
export function AddTodo() {
    const mutation = useMutation({
        mutationFn: createTodo,
        onSuccess: (created) => console.log('Angelegt:', created.id),
        onError: (error) => console.error(error.message),
    })

    return (
        <>
            <button
                disabled={mutation.isPending}
                onClick={() => mutation.mutate({ todo: 'Folien lesen', completed: false, userId: 1 })}
            >
                {mutation.isPending ? 'Speichert…' : 'Todo anlegen'}
            </button>
            {mutation.isError && <p role="alert">{mutation.error.message}</p>}
        </>
    )
}
```

- `mutation.isPending`, `isError`, `isSuccess`, `data`, `error` entsprechen dem Status bei Queries.
- `mutate(variables, { onSuccess })` erlaubt zusätzlich Callbacks pro Aufruf.

## PUT, DELETE und mutateAsync

```typescript
const updateTodo = useMutation({
    mutationFn: ({ id, completed }: { id: number; completed: boolean }) =>
        fetch(`https://dummyjson.com/todos/${id}`, {
            method: 'PUT',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ completed }),
        }).then(r => r.json() as Promise<Todo>),
})

const deleteTodo = useMutation({
    mutationFn: (id: number) =>
        fetch(`https://dummyjson.com/todos/${id}`, { method: 'DELETE' }),
})

updateTodo.mutate({ id: 1, completed: true })
```

- `mutate` ist fire-and-forget, Fehler landen im Mutation-State.
- `mutateAsync` liefert ein Promise (nutzbar mit `await`), Fehler müssen mit `try/catch` behandelt werden.
- `mutationFn` bekommt genau **ein** Argument (die Variables), bei mehreren Werten ein Objekt übergeben.

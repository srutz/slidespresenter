
# React 19 Topics / ViewTransition

`useTransition` ist ein neuer Hook von React19. 

- Komponenten werden im Hintergrund gerendert und dann sichtbar gemacht. 

- In Kombination mit der startViewTransition API des Browsers kann eine Animation gestartet werden und diese kann effizienter ablaufen da der Main-Thread nicht während des Aufbaus der anderen Komponenten blockiert wird.

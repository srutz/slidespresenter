# 4.8 Styling mit Tailwind CSS / Wiederverwendbare UI-Patterns und Komponenten

## Wiederverwendung durch Komponenten, nicht durch @apply

- Lange Klassenlisten werden nicht kopiert, sondern in einer React-Komponente gekapselt
- Die Komponente ist die Abstraktion: Markup, Styling und Verhalten an einem Ort
- `@apply` in eigenen CSS-Klassen ist möglich, aber nicht empfohlen: zusätzliche Namen, Indirektion, schlechtere Wartbarkeit
- Komponenten nehmen `className` entgegen und reichen es mit `cn()` (siehe 4.6) durch, damit Aufrufer anpassen können
- Mit `ComponentProps<'button'>` stehen alle nativen Attribute (`onClick`, `type`, `aria-*`) zur Verfügung

## Button-Komponente

```typescript
import type { ComponentProps } from 'react'
import { cn } from '../lib/cn'

type ButtonProps = ComponentProps<'button'> & {
  variant?: 'primary' | 'secondary'
}

export function Button({ variant = 'primary', className, ...props }: ButtonProps) {
  return (
    <button
      className={cn(
        'rounded-lg px-4 py-2 font-medium transition-colors disabled:opacity-50',
        variant === 'primary' && 'bg-blue-600 text-white hover:bg-blue-700',
        variant === 'secondary' && 'bg-slate-200 text-slate-900 hover:bg-slate-300',
        className,
      )}
      {...props}
    />
  )
}
```

- In React 19 ist `ref` ein normaler Prop und steckt bereits in `ComponentProps`, `forwardRef` ist nicht mehr nötig

## Card- und Badge-Komponente

```typescript
export function Card({ className, ...props }: ComponentProps<'div'>) {
  return (
    <div
      className={cn('rounded-xl border border-slate-200 bg-white p-6 shadow-sm', className)}
      {...props}
    />
  )
}

export function Badge({ className, ...props }: ComponentProps<'span'>) {
  return (
    <span
      className={cn(
        'inline-flex items-center rounded-full bg-blue-100 px-2.5 py-0.5 text-xs font-medium text-blue-800',
        className,
      )}
      {...props}
    />
  )
}
```

```typescript
<Card className="max-w-sm">
  <Badge className="bg-green-100 text-green-800">Neu</Badge>
  <Button className="mt-4 w-full">Kaufen</Button>
</Card>
```

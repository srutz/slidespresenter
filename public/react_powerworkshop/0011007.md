
# 11.7 Formulare und Validierung / Checkboxen

## Checkboxen in React

- Checkboxen funktionieren anders als Texteingaben: der Wert ist ein **Boolean**, kein String.
- Statt `value` + `onChange` mit `event.target.value` verwendet man `checked` + `onChange` mit `event.target.checked`.
- Mehrere Checkboxen für eine Liste von Optionen werden typischerweise mit einem `Set<string>` oder Array im State verwaltet.

```typescript
import { useState } from 'react'

export function CheckboxExample() {
    const [agreed, setAgreed] = useState(false)

    return (
        <div>
            <label>
                <input
                    type="checkbox"
                    checked={agreed}
                    onChange={(e) => setAgreed(e.target.checked)}
                />
                Ich stimme den AGB zu
            </label>
            <button disabled={!agreed}>Weiter</button>
        </div>
    )
}
```

## Mehrere Checkboxen (Mehrfachauswahl)

```typescript
const TOPPINGS = ['Käse', 'Pilze', 'Oliven', 'Schinken']

export function MultiCheckbox() {
    const [selected, setSelected] = useState<Set<string>>(new Set())

    const toggle = (topping: string) => {
        setSelected(prev => {
            const next = new Set(prev)
            next.has(topping) ? next.delete(topping) : next.add(topping)
            return next
        })
    }

    return (
        <div>
            {TOPPINGS.map(t => (
                <label key={t}>
                    <input
                        type="checkbox"
                        checked={selected.has(t)}
                        onChange={() => toggle(t)}
                    />
                    {t}
                </label>
            ))}
            <p>Gewählt: {[...selected].join(', ') || '–'}</p>
        </div>
    )
}
```

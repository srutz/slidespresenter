# 6.8 React mit TypeScript / Type Inference sinnvoll nutzen

## Inferenz nutzen, Annotationen gezielt setzen

- TypeScript leitet viele Typen selbst ab. Überflüssige Annotationen machen Code nur länger.
- Annotationen sind nötig bei:
    - Funktionsparametern und Props
    - leeren Anfangswerten (`[]`, `null`)
    - öffentlichen Schnittstellen (Rückgabetyp von exportierten Funktionen, optional)

```typescript
const [count, setCount] = useState(0)            // number, abgeleitet
const [name, setName] = useState('')             // string
const [users, setUsers] = useState<User[]>([])   // sonst never[]
const [user, setUser] = useState<User | null>(null)
```

## as const und satisfies

```typescript
const ROLES = ['admin', 'editor', 'viewer'] as const
type Role = (typeof ROLES)[number]   // 'admin' | 'editor' | 'viewer'

const routes = {
    home: '/',
    users: '/users',
} satisfies Record<string, string>

routes.home   // Typ bleibt der Literal-Typ '/', Schlüssel sind geprüft
```

- as const: Literal-Typen und readonly statt breiter Typen (string).
- satisfies: prüft gegen einen Typ, behält aber den genaueren abgeleiteten Typ.

## typeof, keyof und ReturnType

```typescript
const defaultSettings = { theme: 'dark', pageSize: 20 }
type Settings = typeof defaultSettings        // { theme: string; pageSize: number }
type SettingKey = keyof Settings              // 'theme' | 'pageSize'

function createStore() {
    return { items: [] as string[], add(item: string) { /* ... */ } }
}
type Store = ReturnType<typeof createStore>

type Params = Parameters<typeof fetchJson>    // Parameter einer Funktion
```

- Typen aus vorhandenem Code abzuleiten vermeidet Duplikate, die auseinanderlaufen.

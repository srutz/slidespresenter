
# 4.11 Styling mit Tailwind CSS / Arbeiten mit Inline-Stilen

## Inline Styles

- Inline Styles können in React-Komponenten verwendet werden.
- Inline Styles sind JavaScript-Objekte, die Styles enthalten.

```typescript
export function InlineStyle() {
    const style = {
        fontSize: 20,
        color: 'red'
    };
    return (
        <div style={style}>
            <h1>Meine Komponente</h1>
        </div>
    )
}
```

## Inline Style "Inline" verwenden

- Inline Styles können auch direkt in JSX verwendet werden.

```typescript
export function InlineStyle() {
    return (
        <div style={{ fontSize: 20, color: 'red' }}>
            <h1>Meine Komponente</h1>
        </div>
    )
}
```

- Achtung. Die ersten `{}` sind für JSX, die zweiten `{}` sind für das JavaScript-Objekt.

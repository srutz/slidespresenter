# 4.2 Styling mit Tailwind CSS / Einrichtung im Vite-Projekt

## Installation mit dem Vite-Plugin

- Tailwind 4 wird in einem Vite-Projekt über das Plugin `@tailwindcss/vite` eingebunden

```bash
npm install tailwindcss @tailwindcss/vite
```

```typescript
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

# 4.2 Styling mit Tailwind CSS / Einrichtung im Vite-Projekt

## CSS-Datei und erster Test

- In der Haupt-CSS-Datei (z.B. `src/styles.css`) genügt eine einzige Zeile

```css
@import "tailwindcss";
```

- Diese Datei wird einmal in `main.tsx` importiert

```typescript
// src/main.tsx
import './styles.css'
```

- Erster Test in `App.tsx`:

```typescript
export default function App() {
  return (
    <h1 className="m-8 text-3xl font-bold text-blue-600 underline">
      Tailwind läuft
    </h1>
  )
}
```

- Mit `npm run dev` starten: Die Überschrift erscheint groß, fett, blau und unterstrichen
- Klassen müssen nicht registriert werden: Tailwind findet sie automatisch in den Quelldateien

## Editor-Unterstützung

- Die VS Code Extension "Tailwind CSS IntelliSense" bietet Autovervollständigung, Hover-Vorschau des erzeugten CSS und Linting
- Die Extension "Prettier plugin for Tailwind CSS" (`prettier-plugin-tailwindcss`) sortiert Klassen automatisch in einer einheitlichen Reihenfolge
- Wird eine Klasse nicht angewendet, hilft ein Blick in die Browser DevTools: Ist die Klasse im Element, aber ohne Regel, kennt Tailwind sie nicht (Tippfehler) oder hat sie nicht erzeugt

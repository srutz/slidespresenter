
# 17.5 Legacy- und Überblicksthemen / "Higher-Order-Components" (HOC) nutzen

## Higher-Order-Components (HOC) sind Funktionen, die eine Komponente als Argument entgegennehmen und eine neue Komponente zurückgeben.

- HOCs sind ein Muster, das in React verwendet wird, um Logik zu teilen und zu wiederverwenden.

```typescript

import React from 'react'

function withCounter(Component) {
    return function WithCounter(props) {
        const [count, setCount] = React.useState(0)
        return <Component count={count} setCount={setCount} {...props} />
    }
}
```

- In diesem Beispiel wird eine Funktion `withCounter` erstellt, die eine Komponente als Argument entgegennimmt und eine neue Komponente zurückgibt.

- Dieses Pattern ist eher unüblich in der modernen React-Entwicklung, da Hooks eine einfachere und klarere Möglichkeit bieten, Logik zu teilen und wiederzuverwenden.

# 8.3 useHooks als Standard-Hook-Sammlung / useDebounce: Suchfeld mit Request

## Problem

- Pro Tastendruck ein Request ist zu viel; `useDebounce` liefert den Wert erst nach einer Ruhepause
- Der Request hängt am **entprellten** Wert, die Eingabe am sofortigen

```typescript
import { useState } from 'react'
import { useQuery } from '@tanstack/react-query'
import { useDebounce } from '@uidotdev/usehooks'

export function UserSearch() {
    const [term, setTerm] = useState('')
    const debouncedTerm = useDebounce(term, 300)

    const { data, isFetching } = useQuery({
        queryKey: ['users', debouncedTerm],
        queryFn: () => fetch(`/api/users?q=${encodeURIComponent(debouncedTerm)}`).then(r => r.json()),
        enabled: debouncedTerm.length > 1,
    })

    return (
        <div>
            <input value={term} onChange={e => setTerm(e.target.value)} />
            {isFetching && <p>Suche...</p>}
            <ul>{data?.map((u: { id: number; name: string }) => <li key={u.id}>{u.name}</li>)}</ul>
        </div>
    )
}
```

# 8.3 useHooks als Standard-Hook-Sammlung / useLocalStorage: Einstellungen

## Persistente Einstellungen

- `useLocalStorage(key, initialValue)` verhält sich wie `useState`, speichert aber unter `key` (JSON) im Browser
- Der Setter akzeptiert einen Wert oder eine Update-Funktion
- Ändert sich der Wert in einem anderen Tab, wird er synchronisiert

```typescript
import { useLocalStorage } from '@uidotdev/usehooks'

type Settings = { theme: 'light' | 'dark'; pageSize: number }

const defaults: Settings = { theme: 'light', pageSize: 20 }

export function SettingsPanel() {
    const [settings, saveSettings] = useLocalStorage<Settings>('settings', defaults)

    return (
        <div>
            <button onClick={() => saveSettings(s => ({ ...s, theme: s.theme === 'light' ? 'dark' : 'light' }))}>
                Theme: {settings.theme}
            </button>
            <p>Einträge pro Seite: {settings.pageSize}</p>
        </div>
    )
}
```

- Typisierung: ob das Paket Typen mitbringt bzw. wie generisch sie sind, in der installierten Version prüfen; sonst den Wert beim Lesen mit Zod validieren (gespeicherte Daten können veraltet sein)

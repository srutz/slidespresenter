# 9.13 HTTP, APIs und Server State / Optimistic Updates

## Idee

- Die UI zeigt das Ergebnis einer Mutation sofort an, **bevor** der Server antwortet.
- Schlägt der Request fehl, wird auf den vorherigen Stand zurückgerollt.
- Sinnvoll bei Aktionen mit hoher Erfolgswahrscheinlichkeit: Todo abhaken, Like setzen, Element löschen.
- Zwei Varianten in TanStack Query v5:
  - **Cache manipulieren**: `onMutate` schreibt mit `setQueryData` in den Cache, Rollback bei Fehler
  - **Über `variables`**: die UI rendert die laufende Mutation zusätzlich, der Cache bleibt unberührt

# 9.13 HTTP, APIs und Server State / Optimistic Updates

## Variante 1: Cache mit Rollback

```typescript
export function useToggleTodo() {
    const queryClient = useQueryClient()

    return useMutation({
        mutationFn: ({ id, completed }: { id: number; completed: boolean }) =>
            updateTodo(id, completed),

        onMutate: async ({ id, completed }) => {
            await queryClient.cancelQueries({ queryKey: ['todos'] }) // laufende Refetches stoppen
            const previous = queryClient.getQueryData<Todo[]>(['todos'])
            queryClient.setQueryData<Todo[]>(['todos'], old =>
                old?.map(t => (t.id === id ? { ...t, completed } : t))
            )
            return { previous } // landet als context in onError
        },
        onError: (_err, _vars, context) => {
            queryClient.setQueryData(['todos'], context?.previous) // Rollback
        },
        onSettled: () => queryClient.invalidateQueries({ queryKey: ['todos'] }),
    })
}
```

- `cancelQueries` verhindert, dass eine ältere Server-Antwort den optimistischen Wert überschreibt.
- `onSettled` läuft bei Erfolg und Fehler und gleicht mit dem echten Serverstand ab.

## Variante 2: über variables

```typescript
const addTodo = useCreateTodo()
const { data: todos = [] } = useTodos()

return (
    <ul>
        {todos.map(t => <li key={t.id}>{t.todo}</li>)}
        {addTodo.isPending && (
            <li style={{ opacity: 0.5 }}>{addTodo.variables.todo}</li>
        )}
        {addTodo.isError && (
            <li style={{ color: 'red' }}>
                {addTodo.variables.todo}
                <button onClick={() => addTodo.mutate(addTodo.variables)}>Erneut versuchen</button>
            </li>
        )}
    </ul>
)
```

- Kein Rollback nötig: bei Fehler verschwindet der Eintrag bzw. wird als fehlgeschlagen markiert.
- Einfacher, wenn die optimistische Anzeige nur an einer Stelle gebraucht wird.
- React 19 bringt mit `useOptimistic` einen eigenen Hook für optimistische UI, der mit Actions und Formularen zusammenspielt. Bei TanStack Query bleiben die obigen Varianten der Standardweg.

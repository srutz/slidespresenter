# 9.14 HTTP, APIs und Server State / Client State vs. Server State

## Zwei Arten von State

- **Server State**: Kopie von Daten, die dem Server gehören (Todos, Produkte, Nutzerprofil). Asynchron, veraltbar, geteilt.
  - Werkzeug: TanStack Query
- **Client State**: Zustand, der nur in der UI existiert (Modal offen, aktiver Tab, Filtertext, Warenkorb vor dem Bestellen).
  - Werkzeug: `useState`, `useReducer`, Context, Zustand
- Server State gehört in den Query-Cache, nicht in einen globalen Store.
- Beide Arten werden in der Komponente kombiniert: Client State bestimmt, **welche** Server-Daten geladen werden.

```typescript
const [search, setSearch] = useState('')                     // Client State
const { data } = useQuery({                                  // Server State
    queryKey: ['products', { search }],
    queryFn: () => fetchProducts(search),
})
```

## Anti-Pattern: Server-Daten in den Store kopieren

```typescript
// Anti-Pattern
const { data } = useQuery({ queryKey: ['todos'], queryFn: fetchTodos })
useEffect(() => {
    if (data) useTodoStore.getState().setTodos(data)  // zweite Kopie, muss synchron gehalten werden
}, [data])
```

- Zwei Quellen der Wahrheit: Store und Cache laufen auseinander, Invalidation und Refetch erreichen den Store nicht.
- Zusätzlicher Code für Loading, Fehler und Aktualisierung, den TanStack Query bereits liefert.
- Gleiches gilt für Redux oder `useState` als Kopie der Query-Daten.
- Stattdessen: Daten direkt aus dem Hook lesen, am besten gekapselt in einem Custom Hook wie `useTodos()`.
- Abgeleitete Werte (Filter, Sortierung) beim Rendern berechnen oder per `select` in der Query.

## Entscheidungshilfe

| Frage | Antwort | Ablage |
|---|---|---|
| Gehört die Information dem Server? | ja | TanStack Query |
| Können andere sie ändern? | ja | TanStack Query |
| Nur in einer Komponente relevant? | ja | `useState` |
| Von wenigen Nachbarn benötigt? | ja | State hochheben, Props oder Context |
| App-weit, ändert sich oft (Theme, Warenkorb, UI-Layout)? | ja | Zustand |
| Soll in der URL stehen (Filter, Seite, Tab)? | ja | Router (Search Params) |
| Formularwerte während der Eingabe? | ja | React Hook Form |

- Faustregel: erst lokal beginnen, nur bei echtem Bedarf nach oben oder in einen Store verschieben.


# 3.12 Komponenten, Props und State / Bedingtes Rendern von Inhalten

## Bedingtes Rendern von Inhalten und Early Return

- Es kommt vor, dass man in Komponenten wenn zum Beispiel Daten noch nicht geladen sind, einen Ladeindikator anzeigen möchte. Dabei wird häufig wenn eine Prop oder eine State Variable noch nicht gesetzt ist, per Return-Statement anderes JSX zurückgegeben.

- ACHTUNG: Die Rules of Hooks verletzt man relativ leicht, wenn man Early-Returns verwendet. Es ist wichtig, dass Hooks immer an oberster Stelle in der Komponente verwendet werden.


```typescript
interface DataProps {
    data: string | null;
}
export function DataComponent({ data }: DataProps) {
    if (!data) {
        return <div>Loading...</div>;
    }
    return <div>{data}</div>;
}
```

- Warum das dann doch kein so großes Problem sein sollte ... Gute Komponenten sind nicht zu lang, haben relativ wenige Zeilen Code und sind somit automatisch übersichtlich und gut wartbar.


# 11.4 Formulare und Validierung / Benutzerdefinierte Formular-Validierung hinzufügen

## Validierung im Event-Handler (weniger guter Ansatz)

- Da durch die HTML5-Validierung nur einfache Validierungen möglich sind, kann es notwendig sein, benutzerdefinierte Validierungen hinzuzufügen.
- Weil wir in den Controlled-Components den Wert des Eingabefeldes im State speichern, können wir benutzerdefinierte Validierungen einfach hinzufügen.
- Unsere Komponenten werden sowieso durch den State gesteuert, also können wir die Validierung direkt in der Komponente durchführen.

```typescript
import { useState } from 'react'

// Beispiel für eine nicht notwendige State-Variable für die Fehlermeldung, da die Validierung auch im Korpus durchgeführt werden könnte.

export function CustomValidationComponent() {
    const [value, setValue] = useState('')
    const [error, setError] = useState('')

    const handleChange = (event: React.ChangeEvent<HTMLInputElement>) => {
        const newValue = event.target.value
        setValue(newValue)
        if (newValue.length < 5) {
            setError('Der Wert muss mindestens 5 Zeichen lang sein.')
        } else {
            setError('')
        }
    }

    return (
        <div>
            <input type="text" value={value} onChange={handleChange} />
            {error && <div style={{ color: 'red' }}>{error}</div>}
        </div>
    )
}
```

In diesem Beispiel wird ein Eingabefeld gerendert, das den Wert im State speichert. Der Wert wird bei jedem Tastendruck im Eingabefeld aktualisiert. Wenn der Wert weniger als 5 Zeichen lang ist, wird eine Fehlermeldung gerendert, die besagt, dass der Wert mindestens 5 Zeichen lang sein muss.

# 11.4 Formulare und Validierung / Benutzerdefinierte Formular-Validierung hinzufügen

## Validierung im Korpus (besserer Ansatz)

- Die Validierung kann aufgrund des zwangsläufig stattfindenden Renderns der Komponente auch im Korpus durchgeführt werden. Dieser Ansatz wird empfohlen, da er die Lesbarkeit des Codes verbessert und der Zustand für den Fehler nicht notwendig ist.

```typescript
import { useState } from 'react'

export function CustomValidationComponent() {
    const [value, setValue] = useState('')

    const handleChange = (event: React.ChangeEvent<HTMLInputElement>) => {
        const newValue = event.target.value
        setValue(newValue)
    }

    let error = ""
    if (value.length < 5) {
        error = 'Der Wert muss mindestens 5 Zeichen lang sein.'
    }
    return (
        <div>
            <input type="text" value={value} onChange={handleChange} />
            {error && <div style={{ color: 'red' }}>{error}</div>}
        </div>
    )
}
```

In diesem Beispiel wird ein Eingabefeld gerendert, das den Wert im State speichert. Der Wert wird bei jedem Tastendruck im Eingabefeld aktualisiert. Wenn der Wert weniger als 5 Zeichen lang ist, wird eine Fehlermeldung gerendert, die besagt, dass der Wert mindestens 5 Zeichen lang sein muss.

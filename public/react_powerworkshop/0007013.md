
# 7.13 Hooks und moderne React Patterns / Verwenden von "useEffectEvent()"

## useEffectEvent

- `useEffectEvent` ist ein Hook aus React 19, der es ermöglicht, nicht-reaktive Logik aus einem Effekt herauszulösen.
- Das Problem: Wenn eine Funktion oder ein Wert im Effekt verwendet wird, der sich häufig ändert, müsste man ihn in die Abhängigkeitsliste aufnehmen — was den Effekt öfter als nötig neu startet.
- `useEffectEvent` kapselt diese Logik so, dass sie immer den aktuellen Wert sieht, ohne den Effekt neu zu starten.

```typescript
import { useEffect, useEffectEvent, useState } from 'react'

export function ChatRoom({ roomId, theme }) {
    const onConnected = useEffectEvent(() => {
        showNotification('Verbunden!', theme)
    })

    useEffect(() => {
        const connection = createConnection(roomId)
        connection.on('connected', onConnected)
        connection.connect()
        return () => connection.disconnect()
    }, [roomId])
}
```

# 7.13 Hooks und moderne React Patterns / Verwenden von "useEffectEvent()"

## useEffectEvent — Warum kein `theme` in der Dependency-Liste?

- `onConnected` ist ein *Effect Event*: es liest immer den aktuellen `theme`-Wert zur Laufzeit.
- `theme` muss **nicht** in `[roomId]` aufgenommen werden — der Effekt verbindet sich nur neu, wenn sich `roomId` ändert.
- Ohne `useEffectEvent` würde man `theme` in die Deps aufnehmen und jede Theme-Änderung würde die Verbindung neu starten.

```
Regel:
  useEffect deps   → reaktive Werte die den Effekt neu starten sollen
  useEffectEvent   → Werte die der Effekt lesen soll, ohne ihn neu zu starten
```

## useEffectEvent — Analytics-Beispiel

```typescript
import { useEffect, useEffectEvent } from 'react'

export function Page({ url, shoppingCart }) {
    const onVisit = useEffectEvent((visitedUrl: string) => {
        logAnalytics(visitedUrl, shoppingCart)
    })

    useEffect(() => {
        onVisit(url)
    }, [url])
}
```

- `shoppingCart` ändert sich oft — würde man es in die Deps aufnehmen, würde jede Warenkorbänderung einen neuen Analytics-Event auslösen.
- Mit `useEffectEvent` liest `onVisit` immer den aktuellen Warenkorb, der Effekt selbst feuert aber nur bei URL-Wechsel.
- Hinweis: `useEffectEvent` darf nicht aus dem Effekt heraus weitergegeben werden.

## Dark Mode mit der dark: Variante

- Mit dem Präfix `dark:` werden Klassen nur im Dark Mode angewendet
- Standardmäßig folgt `dark:` der Systemeinstellung (`prefers-color-scheme: dark`)

```typescript
<div className="bg-white p-6 text-slate-900 dark:bg-slate-900 dark:text-slate-100">
  <h2 className="text-lg font-semibold">Titel</h2>
  <p className="text-slate-600 dark:text-slate-400">Passt sich dem System an.</p>
</div>
```

## Dark Mode per Umschalter

- Soll der Benutzer selbst umschalten, wird die Variante in der CSS-Datei neu definiert
- `dark:` gilt dann, wenn das Element (oder ein Vorfahre) die Klasse `dark` trägt

```css
@import "tailwindcss";

@custom-variant dark (&:where(.dark, .dark *));
```

```typescript
function toggleDark() {
  document.documentElement.classList.toggle('dark')
}
```

- Die Auswahl sollte in `localStorage` gespeichert werden, beim Start wird die Klasse entsprechend gesetzt
- Alternative mit Data-Attribut: `@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *));`

## Design Tokens mit @theme

- In Tailwind 4 wird das Design-System in der CSS-Datei mit `@theme` definiert
- Jede Variable in einem Namensraum erzeugt passende Utility-Klassen

```css
@import "tailwindcss";

@theme {
  --color-brand-500: oklch(0.62 0.19 260);
  --color-brand-600: oklch(0.55 0.2 260);
  --font-display: "Lato Variable", system-ui, sans-serif;
  --breakpoint-3xl: 120rem;
}
```

- Daraus entstehen u.a. `bg-brand-500`, `text-brand-600`, `font-display` und `3xl:`
- Namensräume: `--color-*`, `--font-*`, `--spacing`, `--radius-*`, `--shadow-*`, `--breakpoint-*`
- Alle Tokens stehen außerdem als CSS-Variablen zur Verfügung, z.B. `var(--color-brand-500)`

## Semantische Tokens mit CSS-Variablen

- Für Themes eignen sich semantische Namen, deren Werte im Dark Mode wechseln
- So braucht die Komponente kein `dark:` mehr

```css
:root {
  --surface: white;
  --on-surface: oklch(0.2 0 0);
}

.dark {
  --surface: oklch(0.2 0.02 260);
  --on-surface: white;
}

@theme inline {
  --color-surface: var(--surface);
  --color-on-surface: var(--on-surface);
}
```

```typescript
<div className="bg-surface text-on-surface p-6">Wechselt automatisch das Theme</div>
```

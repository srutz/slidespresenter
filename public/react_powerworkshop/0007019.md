

# 7.19 Hooks und moderne React Patterns / React 19: Actions und useOptimistic

`useOptimistic` kann in Verbindung mit `useTransition` Optimistic Updates implementieren.

- `useOptimistic` gibt zwei Werte zurück: den aktuellen Wert und eine Funktion, um den Wert zu aktualisieren. Letzteres ist wie ein Reducer aufgebaut.


# 11.10 Formulare und Validierung / React Hook Form

## React Hook Form — Grundkonzept

- **React Hook Form (RHF)** ist die meistgenutzte Form-Library im React-Ökosystem.
- Kernidee: Felder werden **nicht kontrolliert** (`value` + `onChange`), sondern per `ref` registriert — dadurch minimale Re-renders.
- Einstiegspunkt ist `useForm()`, das u. a. `register`, `handleSubmit` und `formState` liefert.

```bash
npm install react-hook-form
```

```typescript
import { useForm } from 'react-hook-form'

type LoginData = { email: string; password: string }

export function LoginForm() {
    const { register, handleSubmit, formState: { errors } } = useForm<LoginData>()

    const onSubmit = (data: LoginData) => console.log(data)

    return (
        <form onSubmit={handleSubmit(onSubmit)}>
            <div>
                <input
                    {...register('email', {
                        required: 'E-Mail ist Pflicht',
                        pattern: { value: /\S+@\S+/, message: 'Ungültige E-Mail' },
                    })}
                    placeholder="E-Mail"
                />
                {errors.email && <span style={{ color: 'red' }}>{errors.email.message}</span>}
            </div>
            <div>
                <input
                    type="password"
                    {...register('password', { required: 'Passwort ist Pflicht', minLength: { value: 8, message: 'Mind. 8 Zeichen' } })}
                    placeholder="Passwort"
                />
                {errors.password && <span style={{ color: 'red' }}>{errors.password.message}</span>}
            </div>
            <button type="submit">Anmelden</button>
        </form>
    )
}
```

## React Hook Form — mit Zod

- RHF und Zod werden über `@hookform/resolvers` verbunden.
- Das Zod-Schema übernimmt die gesamte Validierung — kein Mischen von RHF-Regeln und Schema-Logik.

```bash
npm install zod @hookform/resolvers
```

```typescript
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

const schema = z.object({
    email: z.string().email('Ungültige E-Mail'),
    password: z.string().min(8, 'Mind. 8 Zeichen'),
})

type FormData = z.infer<typeof schema>

export function LoginForm() {
    const { register, handleSubmit, formState: { errors } } = useForm<FormData>({
        resolver: zodResolver(schema),
    })

    return (
        <form onSubmit={handleSubmit((data) => console.log(data))}>
            <input {...register('email')} placeholder="E-Mail" />
            {errors.email && <span style={{ color: 'red' }}>{errors.email.message}</span>}

            <input type="password" {...register('password')} placeholder="Passwort" />
            {errors.password && <span style={{ color: 'red' }}>{errors.password.message}</span>}

            <button type="submit">Anmelden</button>
        </form>
    )
}
```

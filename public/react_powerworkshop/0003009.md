
# 3.9 Komponenten, Props und State / Weitergabe von Methoden zwischen Komponenten

## Weitergabe von Methoden zwischen Komponenten

- Methoden können als Props an Komponenten übergeben werden.
- Dadurch können Methoden in Kind-Komponenten aufgerufen werden, die in Eltern-Komponenten definiert sind.

```typescript
import { useState } from 'react';

function Parent() {
    const [count, setCount] = useState(0);

    function increment() {
        setCount(count + 1);
    }

    return (
        <div>
            <h1>Parent</h1>
            <Child increment={increment} />
        </div>
    )
}

function Child({ increment }: { increment: () => void }) {
    return (
        <div>
            <h2>Child</h2>
            <button onClick={increment}>Increment</button>
        </div>
    )
}
```

## Weitergabe von Methoden zwischen Komponenten

- Es spricht nichts dagegen, Methoden in einer separaten Datei zu definieren und zu exportieren.
- Die Setter eines Zustands können auch als Methode übergeben werden. Hier ist aber Vorsicht geboten, da die Methode den Zustand manipuliert und der Zustand an die Komponente gebunden ist. Die Komponente kann aber in der Zwischenzeit zerstört worden sein.

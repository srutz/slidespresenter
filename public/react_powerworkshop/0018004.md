
# 18.4 React und Authentifizierung (Zusatzthema) / Ressourcen schützen und automatische Weiterleitung

- Ressourcen schützen ist auf dem Client nur bedingt möglich.
- Die automatische Weiterleitung kann über die `Redirect` Komponente von `react-router` gelöst werden.

```typescript
import { Redirect } from 'react-router';

function ProtectedRoute() {
    const isAuthenticated = true; // Hier Authentifizierung überprüft werden

    if (!isAuthenticated) {
        return <Redirect to="/login" />
    }

    return (
        <div>
            <h1>Protected Route</h1>
            <p>Only authenticated users can see this content.</p>
        </div>
    )
}
```

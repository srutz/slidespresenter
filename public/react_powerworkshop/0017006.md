
# 17.6 Legacy- und Überblicksthemen / Arbeiten mit dem Paket "Emotion"

- Ein weiteres, sehr altes, Paket, welches das Styling von React-Komponenten vereinfacht, ist Emotion.

- Emotion ist eine CSS-in-JS-Bibliothek, die es ermöglicht, CSS direkt in JavaScript zu schreiben.

https://www.digitalocean.com/community/tutorials/react-react-emotion


```typescript
/** @jsxImportSource @emotion/react */
import { css } from '@emotion/react';

export function App() {
  return (
    <div>
      <div css={css({
        margin: 10,
        padding: 10,
        backgroundColor: '#eee',
      })}>
        This is an example of <code>`css`</code> using an object.
      </div>
    </div>
  );
}
```

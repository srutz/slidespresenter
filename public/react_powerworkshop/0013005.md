
# 13.5 Testing / Modul-Tests

## Beispiel für Modul-Tests

- Mehrere Tests können mittels `describe()` und `it()` in einer Test-Suite zusammengefasst werden.
- it und test sind Synonyme und können beliebig verwendet werden.

```typescript
import { sum } from './math';

// TestModul "sum" mit mehreren Tests für die Funktion "sum"
describe('sum', () => {
  it('should add two numbers', () => {
    expect(sum(1, 2)).toBe(3);
  });

  it('should add two negative numbers', () => {
    expect(sum(-1, -2)).toBe(-3);
  });

  it('should add a positive and a negative number', () => {
    expect(sum(1, -2)).toBe(-1);
  });
});
```

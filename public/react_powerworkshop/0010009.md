
# 10.9 Routing mit React Router / Verschachtelte Routen

## Nested Routes und <Outlet>

- Nested Routes sollten UNBEDINGT verwendet werden um komplexe Layouts anhand einer URL wiederherzustellen, wenn der Benutzer auf eine bestimmte URL navigiert.
- Nested Routes sind verschachtelte Routen, die in einer Komponente dargestellt werden.
- Nested Routes werden in der Parent-Komponente definiert und in der Child-Komponente dargestellt.
- Nested Routes werden in dem `<Outlet>`-Tag dargestellt.

```typescript
import { Outlet } from 'react-router';

export function About() {
    return (
        <div>
            <h1>About</h1>
            <Outlet />
        </div>
    )
}
```


# 10.9 Routing mit React Router / Verschachtelte Routen

## Definition der Nested-Routes

- im Router-Objekt gibt es die Eigenschaft `children`, in der die Nested Routes definiert werden. 

```typescript
const router = createBrowserRouter([
    {
        path: "/",
        element: <Main />,
        children: [
            { path: "/", element: <Page1 />, },
            { path: "/dashboard", element: <Page1 />, },
            {
                path: "/quotes", element: <Page2 />, children: [
                    { path: "/quotes/:id", element: <QuoteDetails /> },
                ],
                errorElement: <Error></Error>
            },
        ]
    },
])
```

- In dieser 3 Ebenen tiefen Nested Route wird die Route `/quotes/:id` in der Komponente `QuoteDetails` dargestellt. 
- Quote-Details wiederum wird im Outlet-Tag der Komponente `Page2` dargestellt.
- Page2 wird im Outlet-Tag der Komponente `Main` dargestellt.
